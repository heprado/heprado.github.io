Básico do Cargo

28/02/2024

programmingcommandrust

O cargo é a ferramenta principal do Rust, abaixo segue as principais atividades que podemos fazer com o Cargo:

Cargo build

Com o comando cargo build podemos criar um binario do nosso projeto, por padrão esse binario é considerado de debug.

No exemplo abaixo estamos executando o cargo build

heprado@marvin:~/code/rust/hello_world$ cargo build
   Compiling hello_world v0.1.0 (/home/heprado/code/rust/hello_world)
    Finished dev [unoptimized + debuginfo] target(s) in 0.75s

Como não especificamos qual é o tipo da build, ele vai gerar o binário como debug e você encontrará o seu binário na pasta target/debug no diretório raiz do seu projeto:

Se você rodar o cargo build com o seu binário já compilado e não tiver feito nenhuma modificação no seu projeto o cargo não irá compilar novamente seu código:

heprado@marvin:~/code/rust/hello_world$ cargo build
    Finished dev [unoptimized + debuginfo] target(s) in 0.00s

Caso você queira compilar seu código para uma versão que não seja de debug, precisamos falar para o cargo que é um versão de lançamento, fazemos isso da seguinte forma:

heprado@marvin:~/code/rust/hello_world$ cargo build --release
   Compiling hello_world v0.1.0 (/home/heprado/code/rust/hello_world)
    Finished release [optimized] target(s) in 0.81s

Você encontrará o seu binário na pasta target/debug no diretório raiz do seu projeto:

Cargo Run

Quando executamos o comando cargo run o cargo fala para o rustc compilar o código e executar sem termos que executar o cargo build e executar na mão

Executando um cargo run:

heprado@marvin:~/code/rust/hello_world$ cargo run
    Finished dev [unoptimized + debuginfo] target(s) in 0.27s
     Running `target/debug/hello_world`
Hello, world!

Podemos ver que depois que o código é compilado ele executa e nos mostra “Hello, world!”.

Também podemos utilizar o cargo run –release para executarmos com todas as otimizações(leva mais tempo).

Outra utilidade util do cargo run é executar com todos os núcleos do processador executando o comando cargo run -j {numero de núcleos}, por padrão o cargo já utiliza o maximo.
