Unário,Decimal e Binário

programmingmatematica

Unário

Todos nos em algum momento da vida já contamos números com a mão, a cada dedo que levantamos adicionamos 1 ao número que estamos pensando:

Essa adição ou subtração que você fez com os dedos é chamada de operação unária, você possui um operando(número) que você vai adicionando ou removendo 1 ou mais.

O sistema unário também é conhecido como base-1 e resumidamente ele representa numeros pela quantidade de números UM que possui por exemplo:

1 = 1

111 = 3

11111111 = 8

Um algoritmo em python que representa isso seria:

def adicao_unaria(mao):
	 mao += 1 #mao = mao + 1

def substracao_unaria(mao):

	if mao != 0: #Se a mao não for zero, não temos dedos negativos rsrsrs.
	
		mao -= 1 #mao = mao - 1

mao = 0

adicao_unaria(mao) #mao = 1, ou seja levantamos um dedo.
subtracao_unaria(mao) #mao = 0, ou seja abaixamos um dedo.

Decimal

Temos também o base-10 ou decimal, esse é o sistema numeral mais utilizado, um exemplo seria o número 181, mesmo que os dígitos dele sejam 1 8 1 você não lê ele como 1 + 8 + 1 = 10 e sim da seguinte forma:

1 x 100 + 8 x 10 + 1 x 1 = 100 + 80 + 1 = 181.

Binário

Os computadores utilizam o sistema numeral base-2, em que cada digito(dedo) representasse um expoente para potencializarmos o 2, sendo:

  • Dedão = 0
  • Indicador = 1
  • Meio = 2
  • Anelar = 3
  • Mindinho = 4

Dessa forma cada dedo levantado significaria a soma da potencia 2 ^ dedo ao operando.

Dedão e Indicador levantados resultaria na seguinte conta:

20+ 21 = 1 + 2 = 3

Já se tivéssemos o mindinho e o anelar levantados:

23 + 24 = 8 + 16 = 24

Até agora vimos binários sendo representados com as posições dos dedos, mas a real forma que os computadores veem binários é pela representação e posição dos bits que só podem representar 0 ou 1.

A representação mais comum de um numero em binário é utilizando 8 bits(1 byte), segue abaixo uma tabela representando um byte:

27 26 25 24 23 22 21 20
128 64 32 16 8 4 2 1

Dependendo da posição do bit e se ele está como 1 devemos somar o valor decimal da coluna, se for 0 pulamos:

128 64 32 16 8 4 2 1 Resultado
1 1 1 1 1 1 1 1
128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 255
128 64 32 16 8 4 2 1 Resultado
0 1 1 0 0 0 0 0
0 + 64 + 32 + 0 + 0 + 0 + 0 + 0 96

Com o sistema numeral binary podemos representar 232 = 256 valores, como começamos do ZERO o maior número decimal que conseguimos representar é 255.
