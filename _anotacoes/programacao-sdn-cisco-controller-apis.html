As controladoras de SDN da Cisco são:

  • ACI, utilizado em DATA CENTERS

  • Meraki, utilizado em redes campus ou menores, é mais simples que o DNA Center, a
    controladora só existe na Cloud.

  • SD-WAN, utilizado para conexões na WAN.

  • NOS, utilizado muito em service providers que possuem diversos vendors dentro de suas infraestruturas.

  • DNA Center, utilizado em redes campus de grande porte e empresas que precisam de diversas funcionalidades na sua rede, temos tbm o DNA Spaces que o DNA Center na Cloud, pois o DNA Center é on-premises.

Meraki

Com as APIs da meraki você , puxar informações ou configurar os devices da sua rede, ele oferece 5 tipos de API:

  • Dashboard API

Gerencia tudo que podemos fazer na dashboard da Meraki, como criar organizações, VLANs, redes etc., também podemos pegar informações para exportamos para uma dashboard única, como por exemplo quantos usuarios temos na nossa infra.

  • Scanning API

Conseguimos puxar informações sobre quem está conectado na rede , tanto devices wifi quanto bluetooth.

  • mvSense API

Prove API Endpoints para conseguirmos puxar informações das cameras da meraki.

  • External Captive Portal

Prove APIs para autenticação externa do Captive Portal da Meraki, se você não sabe oq é captive portal é aquelas paginas que a gente se conecta no wifi do Starbucks.

  • Wireless Health API

São APIs utilizadas para puxarmos informações sobre a rede Wifi, como saúde da rede e latência.

DNA Center

  • Intent API

Nos da informações como as configurações das redes virtuais(VXLAN), saude da rede, devices conectados, quais VLANs estão configuradas em cada porta dos Switches.

  • SWIM API

Para controlar as versões das imagens que estão ou que vão ser configuradas nos switches e routers.

  • PnP API

Utilizada para gerenciarmos as configurações de device Plug and Play(PnP).

  • Operational Tools

Gerenciar templates da CLI dos equipamentos, descobrir caminho entre duas aplicações na rede etc.

  • Authentication API

Nesse ENDPOINT fazemos a autenticação e recebemos um token que deve ser passado em toda requisição.

  • Integration API

API utilizada para fazermos integrações com ITSM(Service Now), outro exemplo seria com o ACI para fazermos a politica de conexão de um usuario fim a fim, do campus até o Data Center.
