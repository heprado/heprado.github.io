Servidores só se conectam aos Leaves
Leafs só se conectam aos Spines
Spines não se conectam diretamente

Podemos ligar um roteador num Spine somente se formos fazer um multi-site fabric de ACI.

ACI NÃO FAZ NAT

Fabric node shells
- CLI
- VSH
- VSH-LC
- Broadcom shell*

Para conectarmos um APIC no Fabric, precisamos desabilitar o LLDP da CIMC, pois a CIMC irá roubar os packets do sistema operacional do APIC.

Se nomearmos um switch com o nome errado e quisermos mudar ele, precisaremos descomissionar ele do fabric, e refazer toda a configuração dele.

Domain Types

Domain 1 - Bare Metal Server
Domain 2 - L2-OUT(Para um switch ACI conversar com um switch da rede legado)
Domain 3 - L3-OUT(Para um switch ACI conversar com um roteador.)
Domain 4 - Virtual Machine
Domain 5 - Fibre Channel

Bridge Domain, funciona como se fosse uma VLAN, todos os Endpoints que estiverem em um EPG vão ouvir o Broadcast de um servidor, não importa o lugar, se o seu Bridge Domain existir em dois data centers distantes, os servers vão ouvir.

Um EPG L2_OUT é um EPG onde estarão todos os servidores da rede que não usa ACI.

O ACI não utiliza por padrão o Protocolo ARP, ele utiliza outro protocolo chamado Hardware Proxy.

Se você estiver utilizando uma rede legado, ativar o protocolo ARP onde você for conectar a rede legado.
