Tuplas

Tuplas são variáveis que podem representar diversos valores, veja o exemplo abaixo:

let tup:(i8,i8,i8) = (1,1,1)

Essa variável irá possuir 3 valores, os 3 sendo do tipo inteiro de 8 bits com sinal de mais ou menos, passamos a ela 3 valores 1,1,1, esses valores podem ser mudados caso a variável esteja declarada como mut mas devem ser do mesmo tipo e não podem extrapolar o tamanho(3) da tupla.

Caso seja necessário que cada valor de dentro da tupla seja uma nova variável você pode desconstruir ela da seguinte maneira:

//O underline serve somente para dizer que não vamos utilizar essas váriaveis.
let (_a,_b,_c) = tup;

Quando passamos valores para tuplas não é necessário que os valores sejam do mesmo tipo, você só precisa especificar antes da seguinte maneira:

let tup:(u8,u16,u32) = (255,65535,4_000_000_000)

Arrays

Arrays também são variáveis que podem representar diversos valores, as diferenças entre arrays e tuplas são que arrays só podem ter valores de um tipo, podemos também ter um array com tuplas dentro para podermos ter diversos tipos dentro de um array;

//let array1[tipo;tamanho] = [valores]
let array1:[u8;2] = [1]

let array2:[(u8,u8);2] = [(0,255),(255,0)];
