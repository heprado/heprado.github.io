Coleta qualquer dados que passa por uma aplicação se esse dado for uma string, assim conseguimos ver se em uma transação um método da aplicação está passando os dados corretamente e quais são esses dados.

Existem dois tipos de Data Collectors:

  • Method Invocation Data Collector, pega parametros, valores de variaveis e valores de retorno do metodo que definirmos.
  • HTTP Requests Collectors, pega URL, parametros, headers, cookies e objetos de sessão.
