• Memorias de um switch
    ****

RAM: Memoria onde ficam as configurações que o switch estão usando atualmente.

Flash: Onde fica guardada a imagem IOS do switch

ROM: Onde fica guardado o bootstrap que é o programa que boota a imagem do IOS.

NVRAM: É onde fica guardado a startup-config.

Comandos massa

Hostname>enable

Hostname#conf t

Hostname(config)#hostname Switch1

Switch1(config)#ip domain-name “exemplo.com”

Switch1(config)#crypto key generate rsa modulus 1024

Switch1(config)#username admin secret 1234

Switch1(config)#line vty 0 15

Switch1(config-line)#login local

Switch1(config-line)#transport input ssh(vai permitir somente trafego SSH no terminal OTIMO NINGUEM MERECE TELNET FODA-SE)

Comandos massa

Hostname(config)#interface f0/1

Hostname(config-if)#switchport port-security(ativa o port security)

Hostname(config-if)# switchport port-security maximum (define o maximo de mac-address que vão ficar atrelados a porta)

Hostname(config-if)# switchport port-security violation “protect,restrict,shutdown”(define o que vai acontecer caso seja detectado um frame de um MAC não registrado)

Hostname(config-if)#switch port-security mac-address sticky (vai atrelar os mac address dinamicamente, quando o primeiro frame for recebido na porta vai atrelar o source mac address a essa porta)

Hostname(config-if)#switch port-security mac-address “MAC-ADDRESS”(Registra o Mac-address que você digitar na porta.)

Se tu só ativar o port-security sem definer nada ele vai usar os padrões que são , maximum 1 , sticky , violation vai ser shutdown.

O COMANDO SHOW MAC-ADDRESS TABLE DYNAMIC NÃO VAI RETORNAR MAIS NADA SE VOCÊ ATIVAR O PORT-SECURITY, AGORA VOCÊ TEM QUE USAR O SHOW MAC-ADDRESS TABLE SECURE.
