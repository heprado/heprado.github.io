Blocos

Na linguagem da Hashicorp chamada HCL(Hashicorp Configuration Language), tudo é definido em blocos de código, segue exemplo abaixo da sintaxe:

tipo_do_bloco nome_do_recurso id_do_recurso {
	minha_config = "valor_da_minha_config"
	minha_config_complexa {
		key = value
	}
}
Tipo do bloco (tipo_do_bloco)

O tipo que esse bloco inteiro representa, os mais comuns são “resource” que determina a criação de um recurso, “data” que busca alguma informação e “variable” que define uma variável do módulo.

Nome do recurso (nome_do_recurso)

Esse valor define qual recurso do provider/módulo que estamos utilizando neste bloco.

Id do recurso (id_do_recurso)

Esse valor é utilizado para nós referenciarmos a esse bloco inteiro em outra parte do código. EX: Se quisermos pegar o valor de minha_config dentro do bloco podemos escrever o seguinte:

nome_do_recurso.id_do_recurso.minha_config

Isso nós retornaria o valor que essa chave contém que é “valor_da_minha_config”.

Chaves (minha_config)

São valores que vamos passar dentro de um bloco para definirmos a configuração por exemplo:

  • Se estivermos criando uma subnet precisamos da CIDR dela, então:
cidr = "172.16.0.0/16"
  • Caso for uma máquina virtual e quiséssemos dar um nome para ela, então:
nome = "nome-da-minha-vm"
Blocos embutidos (minha_config_complexa)

Uma configuração que precisa de varias chaves, então definimos esse bloco embutido para dentro dele definirmos as chaves necessárias para essa configuração.

Object Types

São os tipos de objetos que podemos utilizar no terraform, igual a qualquer linguagem de programação temos string,int/float,boolean, arrays e maps.

string = "minha_string"

number = 1234

bool = true

array = ["oi","tchau"]

map = {nome = "João" , idade = 27}

String - Uma string também conhecida como vetor de caracteres.

Number - Um int/float, ele pode ser tanto numeros inteiros quanto com casas decimais.

Array - Contem diversas strings, ou numbers, ou booleans, sendo que todos os valores DEVEM SER DO MESMO TIPO, cada uma delas tem um index que começa em 0, então se eu fizer array[1] receberíamos “tchau”.

Map - Podemos ter diversos tipos de objetos dentro e podemos chamar eles através das chaves, se fizermos map[nome] receberíamos “João”.
