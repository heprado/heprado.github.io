Em data centers, VLANs eram usadas para alem de diminuir o dominio de falha, segregar o tráfego entre os servidores, mas a quantidade de VLANs(4096) geralmente é muito pouco para um Data Center, então criar uma VLAN para cada grupo de servidores que podiam se conversar na mesma VLAN era impossivel.

Com isso a cisco criou a private VLAN, com isso podemos ter varias VLANs dentro de uma VLAN.

A VLAN principal é chamada de VLAN Primary, nela configuramos todas as outras VLANs que vão estar dentro dela.

Já nas VLANs secundarias podemos ter dois tipos, community e isolated:

Community - Todos os servidores que estiverem nessa VLAN community podem se conversar.

Isolated - Todos os servidores que estiverem nessa VLAN isolated não podem se conversar.

Para configurarmos uma porta para estar numa PVLAN Isolated, só precisamos mapear a VLAN Isolated nela. (VLAN 100 Primary , 20 Secondary Isolated)

Para configurarmos uma porta para estar numa PVLAN Isolated, só precisamos mapear a VLAN Isolated nela. (VLAN 100 Primary , 10 Secondary Community)

Também podemos ter uma porta chamada de prosmicuous , essa porta ouve todas as VLANs dentro da vlan primaria, desde as ISOLATED as COMMUNITY.

Tipos de Private VLAN Trunk

Trunk comum - Taggeia com o ID da onde estiver vindo, se vier de uma VLAN community 101 por exemplo, ele vai mandar pelo trunk com a TAG 101, o outro lado sabe que a VLAN 101 é community então encaminhar o tráfego para essa VLAN.

Promiscuous Trunk - Quando um frame originado de uma vlan secundaria bater nesse trunk ele envia a tag da VLAN primaria, isso é util quando queremos utilizar subinterfaces com encapsulation dot1q, pois assim podemos rotear o tráfego entre VLANs primarias, quando frames chegam nesse trunk ele não mexe em nenhuma tag.

Isolated Trunk ou Secondary Trunk - Nesse modo quando um frame de uma VLAN secundaria bater no trunk, o trunk envia com a TAG da VLAN Secundaria, assim podendo estender essa VLAN para switches que não entendem Private VLAN, quando os frames chegam nesse trunk ele não mexe em nenhuma tag.
