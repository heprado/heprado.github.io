Diminuir a labuta

São um conjunto de ferramentas prontas para serem utilizadas ou customizadas para atender a demanda da aplicação, o objetivo de um framework é remover um pouco da labuta das costas do desenvolvedor, imagine que toda vez que você fosse criar uma aplicação web você precisasse parsear requisições web e transforma-la em um objeto dentro de sua aplicação para conseguir fazer o encaminhamento dessa requisição para a função certa, seria um inferno.
