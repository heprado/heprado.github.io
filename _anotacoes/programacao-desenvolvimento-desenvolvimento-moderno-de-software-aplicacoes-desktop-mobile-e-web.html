Desktop

Resumo

- Atualmente a maioria das aplicações de desktop se comunica com a internet.
- Não necessariamente necessita de acesso a internet para baixar e nem para funcionar.
- Menos mobilidade ao usuário

Aplicações para desktop são criadas pensadas em criar um executável que instala a aplicação e todas ou algumas das funcionalidades dela, a aplicação não necessita necessariamente de acesso a internet, claro com exceções.

Um exemplo seria o Word, você consegue escrever seus documentos e salva-los localmente, mas caso queira acessar de outro dispositivo você teria que colocar salvar ele no google drive ,one drive, enviar vial e-mail, etc…

Outro exemplo seria a calculadora do windows, você não precisa de acesso a internet pra fazer 1+1 = 2.

Essas aplicações hoje em dia são as mais raras por conta da falta de mobilidade que ela prove ao usuário, se você tiver um aplicativo de banco que só funciona no desktop você não conseguiria consultar seu saldo bancário num shopping por exemplo.

Mobile

Resumo

- Android ou iOS
- Maior mobilidade ao usuário
- Não necessariamente necessita de acesso a internet para baixar ou funcionar.

Atualmente existem duas plataformas mobile, Android(Google) ou iOS(Apple), cada plataforma possui uma forma de programarmos a aplicação(existem soluções como Flutter que faz pros dois),

Aplicações mobile são as que mais crescem no mercado por conta da mobilidade que ela prove ao usuário e porque a maioria das pessoas tem acesso a um smartphone atualmente.

As aplicações mobile são parecidas com as de desktop no quesito de se comunicar com a internet, possuem aplicações que você só precisa da internet para baixa-la, e as que necessitam de internet para funcionar.

Web

Resumo

- Necessita de acesso a internet para funcionar.
- Acessada através de navegadores.
- Utiliza HTTP/S (TCP 80/443).
- Pode ser acessada tanto do desktop quanto do smartphone.

Esse tipo de aplicação não é instalada em seu dispositivo, você acessa ele através de outra aplicação chamada de navegador que necessita de acesso a internet por utilizar HTTP/S para acessar a aplicação, o beneficio desse tipo de aplicação é que ela pode ser acessada tanto de um smartphone quanto do desktop, sendo que a maior das dificuldades é manter o layout da aplicação consistente entre as diferentes proporções de tela existentes.

Exemplos de aplicações são o Netflix, Internet Banking de qualquer banco, Lojas, Fóruns, etc..
