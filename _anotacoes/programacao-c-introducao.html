C é uma linguagem de programação de uso geral, ela pode ser utilizada para escrever uma gama de tipos de software como compiladores, sistemas operacionais, programas de linha de comando, programas com interfaces gráficas, podemos fazer basicamente de tudo com ela.

Foi muito associada ao sistema operacional UNIX pois ele foi escrito em C e isso popularizou muito a linguagem pois na época UNIX era o sistema operacional que as universidades utilizavam.

C diferente das linguagens anteriores a ele possui tipos de dados como:

  • char
  • int
  • float
  • string
  • structs
  • arrays
  • unions

Diferentes das linguagens posteriores ao C, os tipos de dados não possuem operações já definidas, digamos que você queira colocar um novo item no final de um array, você vai precisar escrever a função que faz isso, a linguagem não te prove essa funcionalidade.

C oferece somente execução serial, em uma unica thread, com a possiblidade de multi processamento, só que não espere que a linguagem te ofereça corotinas, multi threading para execução paralela.
