Authentication, Authorization and Accounting

AAA geralmente é estabelecido em servidores, neles instalamos aplicações como o Active Directory da Microsoft ou o FreeRadius e usamos ele para nos autenticarmos nos switches/roteadores ou até mesmo em VPNs.

Existem 2 protocolos:

  • Radius - Protocolo aberto, normalmente usado para autenticação de usuarios, somente a senha é encriptada num pacote RADIUS.

  • Tacacs+ - Protocolo proprietario da cisco, a maior diferença do Radius pro TACACS+ é que o TACACS consegue fazer autenticação por comando, ou seja, um usuario escreve o comando show ip ospf neighbors, o roteador vai perguntar para o servidor TACACS+ se você pode mesmo fazer isso, e se sim o comando será executado, ele faz isso para cada comando.

Os pacotes tambem são totalmente encriptados no TACACS enquanto no Radius só a senha é encriptada.

É normalmente usado para autenticação em equipamentos de rede.
