JMX é uma forma de puxarmos informações da aplicação através de uma comunicação cliente servidor, temos dentro da aplicação um servidor JMX que expoe metricas para um cliente JMX.

JMX expoe informações da aplicação através de Mbeans, esses Mbeans são definidos como uma classe dentro da aplicação, essa classe expõe informações sobre a aplicação.


O AppDynamics utiliza JMX para monitorar as aplicações JAVA, podemos também configurar regras de monitoramento de JMX para tipos de aplicações pré-definidas como Tomcat.
