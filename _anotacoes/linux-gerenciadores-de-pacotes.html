DPDK - Gerenciador de baixo nivel de distros Debian, ele instala arquivos .deb

RPM - Gerenciador de baixo nivel de distros Redhat/CentOS, ele instala arquivos .rpm

APT - Gerenciador de alto nivel de distros Debian, ele já baixa todos os pacotes necessarios para o que vc precisa para rodar o programa que você está baixando.

Arquivo onde ficam as urls repositorios que o APT vai buscar os pacotes

/etc/apt/sources.list
E o diretorio onde podemos colocar arquivos com repositorio é o

/etc/apt/sources.list.d

YUM - Gerenciador de alto nivel de distros Redhat/CentOS, ele já baixa todos os pacotes necessarios para o que vc precisa para rodar o programa que você está baixando.

Arquivo onde ficam as urls repositorios que o YUM vai buscar os pacotes

/etc/yum.conf

E o diretorio onde podemos colocar arquivos com repositorio é o

/etc/yum.repos.d
