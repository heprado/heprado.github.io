No ecossistema do Firepower temos 3 APIs principais:

  • FTD API, essa api é utilizada para fazermos automações em um dispositivo Firepower com o FTD instalado.

  • FMC API, essa API é utilizada para automações utilizando o FMC que gerencia todos os outros FTDs.

  • FXOS Chassis API, essa API é utilizada para gerenciarmos e automatizarmos o Chassi do Firepower 9300, esse firepower é como se fosse um chassis UCS 5108, podemos ter diversos FTD dentro dele, tanto fisico como virtuais.

Já na parte de defesa de Endpoints temos 3 APIs:

  • Umbrella API, essa API é feita para parceiros enviarem evento sobre certo dominios para a Umbrella, assim mantendo a base de dados de dominios perigosos mais rica, também podemos fazer o contrario e consumir essa base de dados para nos precavermos.

  • Cisco ISE ERS API, essa api é utilizada para fazermos automatização da plataforma ISE, ele oferece operações CRUD basicamente.

  • AMP API, utilizada para pegar informações sobre os endpoints geralmente.

FTD API

  • Suporta GET,POST,PUT,DELETE
  • Possui uma documentaçao da API igual o NXOS.

Cisco ISE ERS API

  • Suporta GET,POST,PUT,DELETE
  • Utiliza basic HTTP authorization então precisamos passar user:password em base64.
  • Conseguimos passar parametros pela URL, como equals, greater than, etc.

/ers/config/internaluser?filter=name.STARTW.a&filter=identityGroup.EQ.Finance

AMP API

  • Suporta GET,POST,PATCH,DELETE e OPTIONS.
  • Passamos o ID do endpoint que queremos chegar e a API Key do mesmo na URL, escolhemos qual vai ser a API do AMP(Existe uma para cada região) que vamos chamar e a versão.
