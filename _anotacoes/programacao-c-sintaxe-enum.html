Utilizando para juntar diversas constantes e dar nome para elas, em vez de fazermos:

const int Felipe = 1;
const int Eduardo = 2;
const int Henrique = 3;

A gente pode fazer:

public enum Pessoas {
Felipe = 1;
Eduardo = 2;
Henrique = 3;
}

E depois chamar eles como se fossem classes como tipo:

Console.WriteLine(Pessoas.Henrique)

Ele vai printar 3 na tela.
