Rust por ser uma linguagem estaticamente tipada, precisa na hora da compilação do código saber o tipo de todos os dados.

Inferir

O compilador consegue inferir alguns tipos de dados automaticamente, por exemplo:


fn abcd() -> String {

	let abcd = String::new();
	abcd.push_str("abcd");
	
	abcd //retorno
}

fn main() {
	let minha_string = abcd(); 
}

No código acima a variável minha_string não possui um tipo determinado, mas o compilador consegue saber por conta do tipo do retorno da função abcd.

Tipos Escalares

Tipos de dados escalares são dados que possuem somente um valor, como:

  • Números inteiros
  • Números de ponto flutuante
  • Caracteres
  • Booleanos

Cada um desses tipos possuem diversas variantes, um número inteiro por exemplo pode ser de todas essas variantes:

Comprimento Com sinal Sem sinal
8-bit i8 u8
16-bit i16 u16
32-bit i32 u32
64-bit i64 u64
128-bit i128 u128
arch isize usize

A diferença principal entre todos esses tipos são o menor e o maior valor que é possível ser atribuído a uma variável desse tipo e se possuirá um sinal de + ou - no inicio para identificar números negativos.

Para calcularmos qual é o menor e o maior valor possível de cada um desses tipos devemos utilizar as seguintes formulas:

Onde nn é a quantidade de bits da variação do número.

  • Números com sinal:

    • Mínimo

      −(2n−1)-(2^{n - 1})

    • Máximo

      (2n−1)−1(2^{n-1})-1

  • Números sem sinal:

    • Mínimo
      00

    • Máximo
      2n−12^n - 1
