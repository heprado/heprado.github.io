Servidores AAA são usados para nos autenticarmos numa rede, imagine que você tem 100 switches, você vai realmente ir em cada um deles e escrever:

Switch(config)#username henrique secret SEGREDINHO

Fazer isso não é nada simples, então criaram um servidor chamado AAA(Authentication, Authorization, Accounting) com eles conseguimos criar diversos usuarios e utilizar eles pela rede, aumentando bastante a segurança.

Existem dois tipos de servidores AAA:

TACACS+ : Servidores criados pela cisco, ele pode ser instalado em Unix, e uma das coisas mais legais dele é que podemos criar usuarios nele e setarmos exatamente quais comandos da CLI ele pode usar(MUITO MANEIRO).

TACACS USA TCP

Os pacotes no TACACS+ também são totalmente encriptados, no RADIUS só a senha é encriptada.

RADIUS: Servidor padrão aberto, podem ser instalados em diversos SO.

RADIUS USA UDP

Configurando AAA:

TACACS+ -

O NOME DO ROTEADOR E A SENHA QUE VC ENVIOU VÃO ESTAR CONFIGURADOS NO SERVIDOR TACACS+

Aaa new-model
Tacacs-server host “IP”
Tacacs-server key “senha” (para o roteador se autenticar no servidor)
Aaa authentication enable default group tacacs+ local (Nessa sequencia o tacacs+ vai ser usado por padrão, mas caso o servidor não esteja UP, ele tenta se autenticar localmente)
Aaa authentication login default group tacacs+ local

RADIUS

O NOME DO ROTEADOR E A SENHA QUE VC ENVIOU VÃO ESTAR CONFIGURADOS NO SERVIDOR RADIUS

Aaa new-model
radius-server host “IP”
radius-server key “senha” (para o roteador se autenticar no servidor)
Aaa authentication enable default group radius local (Nessa sequencia o radius vai ser usado por padrão, mas caso o servidor não esteja UP, ele tenta se autenticar localmente)
Aaa authentication login default group radius local
