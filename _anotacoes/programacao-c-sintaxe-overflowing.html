Caso você utilize por exemplo o tipo de dado byte:

Byte numero = 255 ;

O tamanho maixmo do dado byte é 255 se vc adicionar por exemplo:

Numero = numero + 1

O numero vai virar 256, que passa do valor maximo do byte, com isso temos um overflow e na hora que printarmos esse valor por exemplo o terminal só vai me mostrar o numero 0.

Para checar se o numero está dando overflow fazer o seguinte:

checked{
Byte numero = 255 ;
Numero = 255 + 1;
}

Assim na hora que compilar ele vai da erro.
