VPN significa Virtual Private Network, ela é composta por:

IPSEC:

  • Confidencialidade

Todos os dados mandados via VPN são encriptados, com isso conseguimos fazer com que pessoas não olhem nossos dados.

  • Autenticação

VPNs fornecem autenticação, para sabermos que quem está recebendo os dados encriptados é realmente a pessoa que desejamos.

Utilizam Pre Shared Keys(PSK) ou Certificados.

  • Integridade dos Dados

Previne que os dados sejam modificados, utilizando hashes.

  • Anti-Replay

Elimina dejavus, um hacker pode muito bem capturar os 3 primeiros pacotes(pacotes de autenticação), e só reenviar para o servidor de VPN, conseguindo assim se autenticar, o anti replay previne isso.

Tipos de VPN

Site to site

Conectar um escritório com outro escritório, criando um túnel IPSEC permanente entre os escritorios, utilizando firewalls ou roteadores com capacidades de firewall.

Client

Cria um túnel da rede de um cliente via internet, por exemplo um funcionário de férias, consegue se conectar na sua rede utilizando um túnel IPSEC.

SSLVPN

Utiliza os mesmos protocolos de criptografia que o HTTPS, para isso o cliente entre em um site, se autentica e lá ele tem acesso a uma intranet da empresa.

DMVPN

Utilizada para conectar múltiplos escritórios, utiliza interfaces GRE.

GRE ( Generic Routing Encapsulation)

O túnel GRE encapsula o pacote IP(layer3) com um header GRE, após isso o pacote é novamente encapsulado em outro pacote IP com o IP publico por exemplo.

Pois lembre, um pacote IP não muda seu destination nem source headers, com o tunel GRE, encapsulamos esses destination e source em outro pacote IP, assim escondendo o real destino e origem.

Com isso conseguimos criar uma conexão ponto a ponto entre dois sites, pois o roteador da operadora nem ninguém vai enxergar essas redes que você está enviando.(NÃO ESTÃO CRIPTOGRAFADAS)

Configurando GRE:

Router 1

Interface g0/0
Ip address 51.23.2.1 255.255.255.252
No shut
Exit
Int tunnel 0
Ip address 192.168.0.1 255.255.255.252
Tunnel source 51.23.2.1
Tunnel destination 73.23.54.1
Exit

Router 2
Interface g0/0
Ip address 73.23.54.1 255.255.255.252
No shut
Exit
Int tunnel 0
Ip address 192.168.0.2 255.255.255.252
Tunnel source 73.23.54.1
Tunnel destination 51.23.2.1

Precisamos de uma rota default nos roteadores para alcançarmos o ISP.

Assim os pacotes vão sair dos roteadores com destino para o ip que setamos no tunnel destination.
