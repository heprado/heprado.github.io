Utiliza protocolos na camada de fisica e datalink totalmente diferentes das LANs, na WAN geralmente utilizam interfaces seriais.

Physical

T1 line = 1.544mbps
E Line = 2.048mbps

O jack na parede é o demarcation point, o ISP traz o cabo do PoP deles até esse demarcation point, lá você conecta um cabo com entrada rj-45, que ligamos no csu/dsu que faz a conversão de sinal analogico para digital, e ligamos na interface serial do roteador.

A Cisco criou a WICs que fazem tudo que o CSU/DSU faz, só que direto na placa, então só precisamos ligar o RJ-45 da parade na WIC diretamente no roteador.

Datalink

  • HDLC = High Level Data Link Control

O HDLC nem sempre foi proprietario cisco, a cisco adicionou o campo type nele e fez ele virar proprietario, com isso conseguimos passar diversos protocolos por ele, como IPX, APPLETALK,IPv4,IPv6.

Protocolo proprietario da Cisco, roteadores da cisco usam esse protocolo por padrão, se for conectar um roteador Cisco em um roteador não Cisco, precisamos trocar o protocolo.

O Protocolo HDLC consegue encaminhar diversos tipos de protocolos roteaveis (IPv4,IPv6,IPX,Apple Talk), por conta de um header dele que se chama Type, nele ele identifica o protocolo.

Esse protocolo só serve para fechar a conexão, ele não tem nenhuma feature.

  • PPP = Point to Point Protocol

Protocolo padrão aberto , utilizado em todos os roteadores, possui diversas features, como autenticação, multilink, compressão.

Temos 2 tipos de protocolos que passam dentro dele:

LCP: Esse protocolo tem varias features, como Loop Prevention, verificar se o link está perdendo muitos frames e desabilitar a interface para o roteador fazer o reroteamento, também controla outros protocolos como CHAP,PAP e PPP MULTILINK.

NCP: Esse protocolo é definido pelo Layer 3, IPCP,IPv6CP, etc…

Multilink : Agrupamento de portas em um único grupo logico, o bom do PPP é que ele realmente faz um Loadbalance, se vc tiver 3 links no Multilink ele vai dividir o pacote por 3 e mandar cada parte por um link, juntando todos no final.

Autenticação: Feature utilizada para fazermos autenticação de um roteador com outro, assim saberemos que do outro lado do link está quem realmente deveria.

Existem 2 tipos de autenticação:

CHAP: Challenge Handshake Autentication Protocol

Autenticação com username e password hasheados.

No CHAP o roteador1 que quer se autenticar recebe uma mensagem challenge do roteado2r que o está autenticando, o roteador1 então manda seu usuario e senha hasheados.

PAP: Password Authentication Protocol

Autenticação com username e password em clear text.

No PAP quem começa o processo de autenticação é o roteador que quer se autenticar, ele envia o usuario e senha em clear text, e o roteador que o está autenticando aceita.

PPP Multilink

Feature do PPP utilizado para juntarmos dois links físicos em um logico.

O PPP Multilink faz load-balancing de verdade, ele pega os pacotes e quebra em 2 se vc tiver 2 links, 3 se vc tiver 3 links etc…, e depois reconstroi na fonte.

Para habilitar precisamos criar uma interface multilink:

interface multilink 1
Encapsulation ppp
Ppp multilink
Ppp multilink group “numero do grupo”(O Numero do grupo precisa ser o mesmo nos dois roteadores)
Ip address 192.168.0.1 255.255.255.252
Int s0/1
Encapsulation ppp
Ppp multilink group “numero do grupo”
Int s0/2
Encapsulation ppp
Ppp multilink group “numero do grupo”

PPPoE

Quando as operadoras começaram a usar o protocolo Ethernet para entregar internet para os clientes, se viu necessário utilizar o protocolo PPPoE para autenticação de usuarios, se não qualquer um poderia ir lá e conectar um modem DSL e pegar internet para sua casa, o PPP foi escolhido pois ele já tinha essa feature de autenticação, então só precisaram simular ela no Ethernet.

Dialer Interface:

Interface virtual onde colocamos todas as configurações do link.

Interface Fisica:

Essa interface será linkada a interface Dialer.

Virtual Access:

Interface criada pelo PPPoE.

Configurando PPPoE:

Interface dialer 1
Dialer pool group 1
Encapsulation ppp
Mtu 1492(Header do PPP é 8bytes)
Ip address negotiated
Ppp chap hostname “usuario”
Ppp chap password “senha”

Interface g0/0
Encapsulation ppp
Ppp-client dial-pool-number1

Após isso vão ser criadas as interfaces virtual access, e o PPPoE vai subir.
