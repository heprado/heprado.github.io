Usuário IAM

Um usuario IAM é uma pessoa OU robo que interage com a API da AWS, ele possui uma ou varias ROLES

Grupo IAM

Um grupo IAM é uma coleção de diversos usuarios que possuem as mesmas roles.

Role IAM

Uma role pode ser atribuida a um usuario ou a um grupo de usuarios e ela que permite o acesso a um recurso atraves de POLICIES.

Policy IAM

Uma policy determina qual role pode acessar qual serviço da AWS.

Tokens de segurança

A AWS utilizada 3 tokens JWTs para permitir acesso a seus serviços atraves do Cognito

  • Identity Token
  • Access Token
  • Refresh Token

Você pode utilizar esse Cognito para autenticar e autorizar os usuarios da sua aplicação utilizando o IAM da AWS.
