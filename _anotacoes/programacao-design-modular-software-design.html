A base de codigo de um programa deve ser muito bem estruturada antes de começarmos a fazer o codigo, isso pois se não fizermos isso vai ser muito complicado depois de adicionar novas funcionalidades ou arrumar bugs.

Hoje em dia as pessoas fazem Softwares Modulares isso é, os componentes das aplicações estão separados como front-end,back-end e banco de dados todo eles são entidades que se conversam e o jeito como o software é escrito afeta muito a escalabilidade desse software, pois um back-end que aponta direto pra somente um banco de dados, caso precise escalonar para mais bancos, teriamos que fazer uma mudança brusca no código que pode quebrar o ambiente inteiro.

Isso também muda de empresa para empresa, por exemplo uma startup faria um ambiente na nuvem em que tudo é escalável pois eles não sabem ainda o quanto vão crescer, diferente de uma grande empresa que quer um ambiente mais simples com que eles consigam prever o que vai acontecer e planejar caso precisem aumentar a infraestrutura.

As aplicações na nuvem são feitas baseadas em software modulares, são pequenas partes que conversam entre si que conversam atraves de REST API, esse modelo é chamado de micro-serviços.

Microserviços

Como dito acima microseviços são um software dividido em pequenas partes que fazem comunicações via APIs, isso faz com que cada funcionalidade do codigo possa ser modificada e escalonada separadamente sem afetar os outros serviços da aplicação, isso ajuda bastante pois não queremos tudo junto em uma caixa só, pois muitas vezes precisamos aumentar o banco de dados mas não precisamos o software de pagamento, se os dois estiverem MUITO acoplados como por exemplo na mesma VM isso atrapalha bastante pois para aumentarmos o banco de dados vamos aumentar tbm o software de pagamento.
