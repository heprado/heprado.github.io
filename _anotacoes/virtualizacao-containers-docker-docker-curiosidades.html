Curiosidades

Docker é uma palavra derivada de Dock Worker.

É um projeto open-source criado pela empresa DotCloud que depois mudou seu nome para Docker Inc, varias empresas contribuem nesse projeto que trouxe os containers o mundo.

O Container mais usado no mundo é o Docker, mas existem outros como Mesos, CoreOS e LXC.

O Docker desktop é utilizado para ambientes de desenvolvimento, podem ser utilizado em Windows, Mac e Linux.
