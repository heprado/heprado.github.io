Rasmus Lerdorf em 1994 queria saber quantas pessoas estavam acessando seu website criado em C, para isso ele criou o Personal Home Page Tools, em 1997 ele queria processar formulários web então ele lanço uma extensão do PHP chamada PHP/FI(Form Interpreter), que ficou conhecida como PHP Versão 2.

Depois de um tempo com o crescimento da linguagem ele mudou o nome para PHP:HyperText Preprocessor.
