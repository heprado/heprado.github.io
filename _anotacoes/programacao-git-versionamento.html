Git é um software de gerenciamento de código criado pelo Linus Torvalds para controlar o desenvolvimento do Linux.

  • Repositório remoto, é o repositório lá no GitHub ou GitLab, onde todos os outros desenvolvedores vão editar o código.

  • Repositório local, é uma versão do repositório na sua maquina, esse repositório fica salvo dentro da pasta .git .

  • Staging Area, é onde preparamos o commit, vamos dando git add de todos os arquivos que modificamos e queremos que as mudanças sejam salvas no repositório local, para depois fazermos o commit logo após o push para o repositório remoto.

  • Working Directory, são os arquivos e pastas do projeto que estão no seu computador.

Comandos do GIT

git config

Configurar variáveis de configuração que o git utiliza, por exemplo para definir o usuário do Git:

git config --global user.name "Henrique Prado" 

git config --global user.email "voce@exemplo.com

git init

Com esse comando criamos um repositório local.

git init nome_do_meu_repositorio

git remote add

Adicionar um repositório remote ao seu repositório local após um git init.

git remote add https://github.com/voce/seu_repositorio_remoto.git

git add

Com esse comando adicionamos um arquivo ou diretório para dentro da área de staging para fazermos o commit

git add teste.py ou git add ~/Projeto

git rm

Com esse comando tiramos um arquivo ou diretório de dentro da área de staging, útil caso não queiramos mais esse arquivo ou pasta dentro do commit.

git rm teste.py

git status

Mostra quais arquivos estão e quais não estão na sua area de staging, isso baseado nos arquivos do ultimo commit do repositório local.

git commit

Com esse comando estamos pegando os arquivos que adicionamos com o git add na area de staging e adicionando ao commit.

git commit -m "Nesse commit eu estudei sobre git"

git pull

Pega todos os arquivos de dentro do repositório remoto e e atualiza o seu repositório local.

git push

Envia todos os seus commits da area de staging para o repositório remoto.

git stash

Salva a configuração de tudo que você adicionou na area de staging, para caso você precise fazer outras modificações no repositório local SEM AS ALTERAÇÕES QUE VOCÊ JÁ FEZ.


git add meu_novo_arquivo

# Salva o arquivo que você adicionou e volta o repositorio para o estado anterior
git stash 

# Volta o repositorio para o estado antes do git stash.
git stash pop

git clone

Faz uma copia do repositório remoto e já cria um repositório para você começar a fazer commits no repositório.

Temos duas formas de fazer clone, isso determina qual será o protocolo de rede será utilizado para enviar os commits então tenha cuidado.

#Repósitorio clonado via HTTPs
git clone https://github.com/voce/seu_repositorio_remoto.git

#Repósitorio clonado via SSH
git clone ssh://voce@github.com/voce/seu_repositorio_remoto.git
