Agentes precisam ser instalados no servidor onde a aplicação está rodando, existem 3 tipos principais de agentes:

  • App Agent, monitora uma aplicação rodando no servidor, Java/Python/Node.JS etc.
  • Machine Agent, monitora o hardware do servidor, para podermos saber se um problema na aplicação está acontecendo por conta de falha de hardware.
  • Database Agent, monitora databases, oracle/mysql/mongodb etc.

Com os agentes instalados podemos monitorar as transações entre as diversas partes da aplicação, o agente faz isso criando um GUID(Global Unique Identifier) para cada metodo sendo chamado no codigo, assim conseguimos fazer o tracking dessa chamada para outra parte da aplicação. Isso vale também para queries em banco.

Para injetar em GUID dentro das transações o agente do AppDynamics utiliza ByteCode Instrumentation(BCI), que é uma forma de injetar codigos dentro de outro codigo enquanto ele está rodando ou sendo compilado,

O agente funciona da seguinte maneira:

  • Sempre é o agente que começa a comunicação utilizando HTTP ou HTTPS para a controladora.
  • O agente faz um pull na controladora pedindo as configurações que devem ser aplicadas nele, esse pull é feito a cada 60 segundos.
  • Ele reporta metricas sobre as transaçoes para a controladora a cada 60 segundos.
  • Se essa transação for uma transação nova que o agente não tinha conhecimento ele reporta para a controladora 10 segundos após.
