Tabela de Roteamento

Contém as rotas que o roteador está usando atualmente.

Criterios de escolha para uma rota:

  • Next Hop: O próximo salto para a rede precisa ser de uma rede que o Roteador conheça.

  • Route Specificity: Quanto mais especifica for a rota melhor, por exemplo , recebi duas rotas 10.0.0.0/8 via int 1/1 e 10.0.1.0/24 via int 1/2, o roteador escolheria a rota da interface 1/2

  • Administrative Distance:

Se um roteador tiver duas rotas para o mesmo lugar, mas de protocolos diferentes, ele utiliza a distancia administrativa para fazer o desempate, quanto menor for a distancia administrativa, mais confiável a rota será.

  • Metric:

O ultimo critério de desempate é a métrica, cada protocolo tem sua métrica, e utiliza isso para escolher as melhores rotas, exemplo seria HOP COUNT do RIP, quanto menos roteadores eu passar para chegar em uma rede, melhor.

O ROTEADOR SEMPRE VAI ESCOLHER A ROTA ESPECIFICA MESMO SE A DISTANCIA ADMINISTRATIVA E A METRICA FOR MENOR.

  • Floating Route = Uma rota estática com distancia administrativa maior que a dos protocolos de roteamento.

Tipos de Protocolos de Roteamento

  • Link State :

Tem um mapa com a rede toda, utiliza mais memoria, e não precisa de nada para prevenir loops

  • Distance Vector:

Conhece somente as rotas que o roteador vizinho divulgou para ele, utiliza menos memoria e precisa de mecanismos para prevenir loops.

Um dos mecanismos que previnem loops são os números de AS (BGP) e split horizon (RIP e EIGRP).

Caso o split horizon esteja ativo em um roteador EIGRP/RIP, ele não vai enviar rotas pelas portas que ele recebeu essas rotas, assim evitando loops.
