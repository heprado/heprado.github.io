Custom dashboards são utilizadas para criamos dashboards customizadas para os diferentes tipos de profissionais que vão consultar o AppDynamics para alguma informação, por exemplo:

  • Uma pessoa de business quer ver quantas vendas foram feitas na aplicação, podemos criar um dashboard.
  • Um desenvolvedor que ver quais classes são as mais chamadas da sua aplicação, podemos criar um dashboard.

Maneiro que podemos importar essas dashboards via iframe ou atráves de uma url, dá pra jogar dentro do grafana muito mais facil assim :)

Dashboard Templates

Dashboard templates são templates que podemos criar e aplicar na dashboard dos tiers e nodes, isso é bem util caso queiramos customizar toda as dashboards.
