Call Manager

O CUCM utiliza APIs baseadas em SOAP então é somente XML que utilizamos para nos comunicarmos com a API dele, não conseguimos utilizar JSON.

A API dele se chama AXL API, e podemos utilizar ela para gerenciar dispositivos, criar usuarios e pegar informações sobre o sistema em sí.

A AXL API utiliza HTTP/1 e a autenticação dela é feita através de Basic HTTP Authentication, mandamos um header Authentication com a string “usuario:senha” encodada em Base64.

Temos tbm a UDS API que é utilizada para integrações de aplicações Web com o Call Manager.

Finesse

Ele possui diversas APIs e muitas delas são internas do sistema:

  • Finesse Desktop API, utilizada para ver informações do desktop como ligações ativas, quem está usando etc.
  • Finesse Configuration API, servem para configurarmos o ambiente inteiro por ela.
  • Finesse Serviciability API, informações de log basicamente
  • Finesse Notifications API, manda notificações como, tal funcionario saiu da mesa e foi almoçar.

Cisco Webex Teams

Conseguimos criar bots, gerenciar espaços, ler mensagens, etc.

Os metodos aceitados são:

  • PUT
  • GET
  • POST
  • DELETE

Como autenticação eles aceitam Oauth e access token, precisamos criar um token especifico pra um bot tbm.

Cisco Webex Meetings

O meetings possui 4 tipos de APIs:

  • XML API, essa é utilizada para fazer tudo que quisermos automaticamente dentro do Webex Meetings, o cEVENT da cisco utiliza as APIs XML para criar os eventos por exemplo.
  • URL Based API, utilizada para integrar portais já existentes de uma empresa, tipo entrar em uma chamada através do portal da sua empresa, os parametros das requisições são passados via URL.
  • TAPI, essa é utilizada para fazer integrações de outros sistemas de teleconferencia com o Webex Meetings, exemplo seria o Teams da Microsoft com o Webex Meetings lá dentro.
