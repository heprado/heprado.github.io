O Cognito consegue te auxiliar a cadastrar,autenticar e autorizar os usuarios da sua aplicação tanto se ela for web ou mobile. Após autenticar e autorizar o Cognito prove tokens com acesso temporario a recursos autorizados da AWS ou qualquer serviços atrás de um API Gateway, você pode utilizar varios provedores de identidade famosos como Facebook Twitter Google até o Active Directory da Microsoft ou integrar seu proprio provedor, ele só precisa implementar SAML ou OpenID Connect.

User Pools

Ele abstrai os tokens recebidos de outros identity providers(provedores de identidade) e prove um token para você autorizar o usuario utilizando o sdk do User pool.

Você também pode criar grupos de user pools para dar perfis diferentes para os usuarios logados.

Identity pools

Após a autenticação utilizando o user pool, você consegue autorizar os acessos a recursos internos da AWS como suas Lambdas, Dynamo DB, API Gateways, utilizando um user group hipotetico “DEFAULT” você pode dar acesso somente a API Gateways, agora se o user group hipotetico for “ADM” você pode dar acesso a tudo.

Senhas Comprometidas

O Cognito consegue identificar usuarios e senhas comprometidas que foram expostas através de algum vazamento de dados e impedir o usuario de cadastrar, pedindo um novo par de usuario e senha.

Validação de email e telefone

Automaticamente envia código de verificação para um email ou SMS.

Autenticação Adaptativa

Utilizando listas da internet de IPs comprometidos ou uma nova localidade do usuario por exemplo podemos mudar como o usuario devera se autenticar.

Digamos que o usuario sempre logou de São Paulo mas agora estão tentando logar o mesmo usuario de outra cidade, podemos pedir para essa autenticação utilizar Multifactor Authentication, pedindo um token de acesso enviando via SMS para o telefone cadastrado.

Historico de login

Ele retem 2 anos de historico de login, podemos utilizar o token para rastrear quais serviços foram acessados por ele.

Fluxo de autenticação com API Gateway

  • App autentica com a User pool
  • Recebe os 3 tokens JWTs
  • App abre uma requisição com o Identity Token e o Access token no header e envia para o API Gateway.
  • API Gateway valida tokens com o user pool.
  • Permite o acesso a lambdas e APIs atrás do API Gateway.

Fluxo de autenticação com Identity Pools

  • App autentica com a User pool
  • Recebe os 3 tokens JWTs
  • App envia uma requisição com o Identity Token e o Acesso Token no header para o Identity Pool(federated identities)
  • Identity Pool valida com o User Pool o Identity Token enviado.
  • Prove credenciais temporarias para acesso DIRETO a recursos da AWS.
  • App assina o payload e envia para o recurso.
  • Recurso checa as politicas associadas as credencias no IAM
  • Caso tenha permissão ele retorna o que foi pedido no payload.

Custo

A AWS cobra o uso do cognito por usuario ativo no mês, todo usuario que acessa algum recurso dentro da AWS é considerado ativo.

O preço por MAU após 50,000 MAUs é baseado por região.

O preço diminui quanto mais MAUs tiverem.

Free tier

Você pode ter 50,000 MAUs no maximo se a autenticação for diretamente no cognito e não em outro provedor de identidade.

Você pode ter somente 50 MAUs para usuaros autenticados em outros provedores de identidade utilizando SAML.
