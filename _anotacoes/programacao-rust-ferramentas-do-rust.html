Rustup

Utilizada para gerenciar a sua instalação do compilador do rust, com essa ferramenta podemos:

  • Atualizar o compilador.
  • Instalar toolchains para compilar para outras plataformas.
  • Checar a versão do compilador.
  • Mudar a versão do compilador de estável para beta, nightly etc..

Cargo

Cria uma build(compila) do seu projeto, baixa e controla as dependências do projeto, executa a maioria das tarefas em Rust, você raramente vai precisar utilizar o rustc para compilar seu código na mão.

Rustc

Compilador do rust, primeiro o rust checa o código, se estiver tudo ok ele compila o código para LLVM-IR(Intermediate Representation), esse código gerado é passado então para LLVM que cria um binário para a plataforma desejada.
