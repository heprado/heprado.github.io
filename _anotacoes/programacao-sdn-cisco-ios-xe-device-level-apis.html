Intent Based Network

O IOS-XE é um sistema operacional baseado nessa filosofia de IBN, Intent based network significa pegar o que o negocio ou aplicação precisa e traduzir isso para politicas de rede, como configurações de protocolos de roteamento, VLANs etc.

IOS-XE é um software utilizado tanto em Routers quanto Switches, Access Points e controladoras Wireless, assim conseguimos automatizar a rede campus por completo.

Automatizando o IOS-XE

Temos três formas de automatizar o IOS-XE:

  • Utilizando DNA Center, esse equipamento é a controladora da Cisco para redes Campus, é uma controladora que abstrae diversas propriedades da rede e faz com que você configure tudo atraves somente da sua intenção.

  • Utilizando outra controladora de SDN ou NMS Servers, o IOS-XE tem uma NBI(North Bound interface) que podemos utilizar para fazermos integrações com outras ferramentas.

  • DIY, basicamente escrever um script em python que vai configurar todos os equipamentos, suporta tanto NETCONF(XML) quanto RESTCONF(JSON).

IOS-XE APIs

NETCONF

Com netconf conseguimos configurar o equipamento tanto utilizando YANG Models representados em XML, como comandos da CLI, o mais comum hoje em dia é YANG MODEL.

O Protocolo utilizado para comunicação entre a controladora e o equipamento é SSHv2 então a porta 22 precisa estar liberada.

NETCONF utiliza RPC( Remote Procedure Call ), e suporta diversos comando que precisamos passar no body da requisição como <get-config>.

RESTCONF

Com RESTCONF a coisa já começa a ficar boa né, já utilizamos HTTP como protocolo de transporte (OBRIGADO)

Os Headers Content-Type e Accept precisam ser passados, para dizermos ao equipamento qual o conteudo do body e o que esperamos receber de resposta, os mais comuns são:

  • application/vnd.yang.data+json for JSON
  • application/vnd.yang.data+xml for XML

    gNMI

    gNMI é um protocolo criado pela Google, ele utiliza o gRPC como protocolo de transporte, e podemos utilizar YANG models para configurarmos os equipamentos

Python IOS-XE

Existem duas formas de usarmos python para configurar um equipamentos IOS-XE, utilizando o script python em nossa maquina e conversando com o IOS através de SSH com NETCONF, o chato desse tipo de comunicação é que precisamos nos autenticar para executarmos os comandos. Ou utilizando o Guest Shell, que é um Linux dentro do IOS-XE, podemos executar o script python dentro do proprio equipamento assim não precisamos nos autenticar :)
