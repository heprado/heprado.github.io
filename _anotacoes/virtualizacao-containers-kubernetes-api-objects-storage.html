Antes no K8s os Pods só conseguiam acessar storage dentro do proprio node, essa storage era chamada de “Volumes”, isso era muito ruim pois caso um Pod em outro Node quisesse acessar esse dado dentro do Volume ele não conseguia, para isso surgiram os “Persistent Volume” que são armazenamentos compartilhados entre os nodes usando NFS, iSCSI ou outro protocolo.
