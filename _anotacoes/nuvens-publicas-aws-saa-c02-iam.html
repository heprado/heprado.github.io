IAM é utilizado para authentication(QUEM?) e authorization(Que que esse mlk pode fazer).

As duas formas de authentication que temos são Roles e Users as principais diferenças são:

  • Roles

Utilizada geralmente para serviços da AWS, esse tipo de autenticação não gera um access key id e uma secret access key estatica como os Users.

Um exemplo seria uma aplicação dentro de uma EC2 precisa acessar um bucket S3, poderiamos criar um User e gravar estaticamente o access key id e a secret access key dentro da aplicação, com role podemos pegar essa credencias nos metadados da EC2, só precisamos de um SDK da AWS.

  • Users

Utilizada geralmente para acessos de usuários reais, como um engenheiro que precisa de acessos a sua conta da AWS.

  • Policies

São o que os Users ou Roles que tiverem essa policy configurada neles podem fazer.
