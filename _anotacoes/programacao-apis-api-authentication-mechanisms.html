APIs são recursos publicos que geralmente estão abertos na internet, para isso precisamos de uma forma de evitar ataques e identificar usuarios para isso utilizamos, os termos utilizados para definir isso são:

  • Authentication, é ato de identificar um usuario ou sistema.

  • Authorization, é classificar quais permissões esse usuario tem em nosso sistema(API).

Geralmente utilizamos os headers de uma requisição HTTP para nos autenticarmos em uma API, utilizar ou o header Authorization, X-API-Key ou Cookie.
