Resumo

- Codifica a interface gráfica
- Codifica interações com o servidor

Quem executa essa função trabalha na codificação da aplicação que ira rodar dentro do dispositivo do cliente, sendo ela de desktop, mobile ou web.

A aplicação é criada utilizando as definições feitas por quem executa as funções de Experiencia de usuário(UX) e Design de Interface de Usuário.

Essa função sempre está em contato com o Back-end, grande parte das interações do usuário são enviadas para o servidor onde o desenvolvedor back-end definiu o que o usuário está buscando ao interagir com certa parte do sistema.
