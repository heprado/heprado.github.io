Cisco AVE veio para substituir o antigo AVS, o AVS era um switch virtual que instalavamos no kernel do ESXi, e por ele controlar as redes virtuais do ESX com o ACI, isso não é mais possivel pois a vmware fechou o kernel dele para todos os 3rd party switches.

Caso vc já tenha feito a integração do ACI com o vDS, os port-groups já serão automaticamente criados, só precisamos colocar a interface inside do AVE no mesmo portgroup que essas private vlans.

Para o trafego sair para a internet ou para outro lugar na rede, precisamos utilizar um trunk para fora do host ESX, esse trafego vai sair por uma vmnic conectada ao ACI, a interface virtual do AVE vai fazer um tunel VxLAN com o ACI.

E tambem temos a interface de gerencia que vamos conectar no portgroup mgmt, para podermos fazer ssh no AVE.
