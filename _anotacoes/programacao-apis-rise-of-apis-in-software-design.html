O software através do tempo evoluiu muito, pensando por exemplo no pacote Office, temos hoje em dia diversas opção onde podemos usa-lo ao em vez de somente aquele client pesado que instalavamos nos nossos computadores, podemos usar ele hoje em dia tanto nos navegadores tanto dos celulares quanto dos PCs(Web Application).

Hoje em dia em aplicações modernas geralmente vemos essas 3 trends:

  • Web Application
  • Cloud Services(Bucket S3 para guardar imagens da pagina HTML por exemplo)
  • Open Source(Reduz e muito o custo e o tempo de um projeto, tempo = dinheiro)
  • Integração com Midias Socias (Exemplo seria vc se conectar em um site utilizando a conta do Facebook, ou aquelas janelas que aparecem em uma pagina Web com a pagina do facebook do serviço)
  • Aplicativos de celulares(Que parecem as web applications)

APIs

Application Programming Interface, é uma interface para que sistemas se comuniquem, um exemplo seria um site conversando com um bucket s3 da amazon para servir imagens, ou um middleware conversando com um banco de dados que serve um API como o MongoDB ou o RDS da Amazon.

As APIs facilitam muito a programação de um sistema, quando a pessoa cria uma API ela já pensa em diversas funcionalidades que outros desenvolvedores podem querer utilizar da aplicação dela e cria diversas chamadas que podem ser feitas nela para servir essas funcionalidades, como por exemplo no Cisco ACI, podemos criar um EPG através da API dele, pois o cara que desenvolveu o ACI, fez um chamada API que por de trás dos panos executa diversas funções no código dele que faz com que seja possível criar o EPG automaticamente.

Sistemas Distribuídos

Sistemas distribuidos nada mais são do que, aplicações que chama outras aplicações através de APIs, pense por exemplo em um workflow de automação do deploy de uma VM, todo o processo de chamadas de API para que o codigo do desenvolvedor chegue na VM é um sistema distribuído.

Basicamente são a junção de diversas funcionalidades de diversas aplicações para chegar a um objetivo, seja esse demonstrar uma pagina web para um usuario, ou criar um topologia super complicada com um click.
