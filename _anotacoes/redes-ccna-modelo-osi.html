É um modelo de referencia que foi criado para padronizar a comunicação de dispositivos processadores, permitindo a interoperabilidade entre eles.

Consiste em 7 camadas:

  • Application

A camada mais próxima do usuario, nessa camada estão protocolos como FTP, HTTP,HTTPS, DNS, prove a disponibilidade da aplicação na maquina cliente e na maquina servidor.

PDU: DATAGRAM

  • Presentation
    Camada responsavel pela formatação dos dados(ASCII), comprime os dados(JPG,GIF), e encripta eles(TLS,SSL).

PDU: DATAGRAM

  • Session

Por exemplo temos uma sessão de download que está usando FTP, e uma sessão que está mandando e-mails usando SMTP, essa camada mantem os fluxos de dados separados.

PDU:DATAGRAM

  • Transport

Camada responsavel pelo transporte de dados, divide os datagramas em diversos segmentos na origem e reconstroem eles na fonte.

Possui controle de fluxo com o protocolo TCP(Transmission Control Protocol), que através do algoritmo triple way handshake garante a entrega dos segmentos ao destinatario, o TCP também faz o Windowing que define o tamanho dos segmentos que serão transmitidos na comunicação.

Também temos o protocolo UDP que não possui ele controle de fluxo de dados, não se preocupa se o destinatario recebeu o segmento.

PDU: SEGMENT

  • Network

Camada responsavel pelo transporte de dados entre sistemas que não estão diretamente conectados, faz esse transporte atraves do protocolo Ipv4 ou Ipv6, esses protocolos são roteaveis e podem ser transmitidos entre redes diferentes com ajuda de roteadores, também temos os protocolos de roteamento (RIP, RIPV2,OSPF,EIGRP,BGP), esses protocolos trocam router update packets para preencherem suas tabelas de roteamentos e criarem os caminhos entre as redes.

PDU: Packet

  • Datalink
    Camada responsavel pelo transporte de dados entre sistemas diretamente conectados, faz o transporte através do MAC Address, que é o endereço fisico único de cada equipamento.

Evita colisões atraves do CSMA/CD e garante a a intregridade dos dados atraves do trailer FCS.

Possui duas sub camadas:
- Subcamada LLC:
Responsavel pela identificação dos protocolos da camada de Rede, um computador lê o cabeçalho LLC para entender qual o protocolo usado( Ipv6, ipv4).
- Subcamada MAC:
Define como os frames serão formatados e transmitidos pelos diversos meios fisicos(Ar,Luz,Eletrico).

PDU: FRAMES

  • Physical

Camada onde ficam os meios fisicos onde os dados passam(Fibra otica, Cabo UTP, Wi-Fi,5G)

PDU : Bits

Modelo TCP/IP é o mais usado hoje em dia, ele aglomera as camadas do modelo OSI em camadas menores.
