No PHP temos duas formas de criarmos erros:

<?php

trigger_error("Quebrou o brinquedo =(",E_USER_ERROR);

e

<?php

function my_func():void {
	throw new Exception("Função my_func quebrou =(");
}

A maior diferença entre o trigger_error() e as Exceptions são os níveis de erro que cada uma consegue passar, a Exception sempre vai ser um erro de alguma ação do usuário, já o trigger_error() temos muito mais opções como:

  • E_ALL = TODOS OS ERROS.
  • E_ERROR = Erros que faz o script parar.
  • E_WARNING = Erros que não fazem o script parar.
  • E_PARSE = Erros de escrita do código, fazem o script não executar.
  • E_NOTICE = Somente um aviso, podendo ser um possível erro ou não.
  • E_USER_* = Habilita erros gerado pelo programador, esses erros são criados através da função trigger_error().
