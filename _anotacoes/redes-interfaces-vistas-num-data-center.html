• vNIC

    • Pode ser uma vNIC que conecta uma VM a um vSwitch
    • Pode ser uma vNIC criada numa VIC

  • vmNIC

    • Uma interface no vSwitch que está atrelada ou a uma interface real, ou a uma vNIC que a VIC criou.

  • vSwitch

    • Funciona como um switch de verdade só que no ESXi

  • vmKernel Port

    • Esse tipo de porta tem varias funcionabilidades
      • vMotion traffic
      • Fault tolerance (FT) logging
      • Management traffic
      • vSphere replication traffic
      • iSCSI traffic
      • NFS traffic
    • O ESXi cria uma dessas chamada vmk0 quando você instala ele, essa vmk0 usa o mesmo mac-address da interface fisica que está ligada.

  • SCSI

    • Protocolo usado para um S.O se comunicar com um HD
    • Como se fosse a layer 2 do modelo OSI só que para SAN

  • iSCSI

    • Protocolo usado para um S.O se comunicar com um storage e reconhecer ele como se fosse dele, através de uma rede Ethernet.
    • Como se fosse a Layer 3 do modelo OSI só que para SAN

  • Fibre Channel

    • Protocolo usado para um S.O se comunicar com um HD
    • Como se fosse a layer 2 do modelo OSI só que para SAN

  • Fibre Channel Over Ethernet

  • Protoco usado para um S.O se comunicar com um storage e reconhecer ele como se fosse dele, através de uma rede Ethernet.

  • Como se fosse layer 3 do modelo OSI so que para SAN
