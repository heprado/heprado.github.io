Quando um exit point ou seja uma requisição é feita de um node para outro é identificado pelo appdynamics, essa transação é marcada como se estivesse indo para um backend, caso esse backend não seja instrumentado pelo AppDynamics, podemos fazer rules especificas para pegar essas transações.
