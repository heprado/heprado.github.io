O Docker funciona com 3 componentes :

Docker Client - Esse client geralmente é a CLI que faz as chamadas na API do do Daemon.

Docker Daemon - Esse daemon é um servidor que controla os containers, ele expoe uma REST API para poder ser controlado, esse Daemon pode estar em qualquer host na rede que o client vai conseguir fazer as chamadas na API dele.

Container Registry - No Container Registry ficam todas as imagens que não estão no Docker Host, podemos fazer um docker pull desse registro e guardamos a imagem dentro do host.
