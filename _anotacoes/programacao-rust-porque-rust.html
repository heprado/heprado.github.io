Rust é uma linguagem baixo nível, com ela podemos escrever códigos que implementam funcionalidades da forma que quisermos, exemplos disso são :

  • Gerenciamento de memoria
  • Concorrência
  • Estrutura de dados.

Em linguagens mais alto nível costumamos ver isso abstraído para nos com alguma API/ABI (geralmente escrita em C ou C++) que faz todo o trabalho “pesado” para nos, só precisamos implementar a lógica em cima dessas API/ABI e seguir com nossas vidas.

Com o Rust temos a chance de chegar mais longe dentro do sistema operacional sem utilizar linguagens como C e C++ que sabemos que possuem diversas “armadilhas” que podem quebrar o nosso software como:

Segurança de tipos

O compilador nos garante que nenhuma operação que não possa ser executa numa variável seja executada.

Segurança de memoria

Referencias(ponteiros) no rust sempre apontam para uma memoria valida.

Livre de corrida de dados

Threads acessando e modificando a mesma variável são impossíveis por conta do borrow checker.

Podemos também escrever aplicações consideradas “alto nível” como CLIs(Command Line Interfaces), REST APIs(Representational State Transfer Application Programming Interfaces), GUIs(Graphical User Interfaces) e Servidores Web, Rust nos propõe uma gama grande de possibilidades como todas as linguagens de programação.
