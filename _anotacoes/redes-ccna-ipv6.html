Global unicast = Similar ao IP publico do IPv4, se utiliza do 2000::/3, é só setar uma interface ou host com esse IP que ele já é considerado Global Unicast pelo router / host.

Unique local = Similar ao ip privado do ipv4, não pode ser roteado para a internet.

Link local = São Ips utilizados somente em uma subnet, não podem ser roteados para redes diferentes, são usados para conexões ponto a ponto.
