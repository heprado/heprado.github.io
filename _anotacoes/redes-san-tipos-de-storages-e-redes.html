DAS ( Direct Attached Storage ) - É o HD conectado direito na barriga do servidor, ou até mesmo o HD conectado agora mesmo dentro do seu PC, significa que o computador não passa por uma rede até chegar ao storage, geralmente conectado com interfaces SAS ou SATA do HD até a Motherboard ou RAID Controller.

NAS ( Network Attached Storage ) - É uma storage dedicada ou um servidor utilizando CIFS/SMB/NFS para compartilhar uma pasta com outros computadores na rede, isso é necessario para caso eu não queria guardar os arquivos dentro do PC, por motivos de backup ou somente pois eu quero que outras pessoas consigam acessar eles.
