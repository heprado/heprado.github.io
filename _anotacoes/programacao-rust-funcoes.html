Declarando

Funções são declaradas com a palavra chave fn, segue abaixo um exemplo:

fn outra_funcao() {
  println!("Outra função");
}

fn main() {
	outra_funcao(); 
}

A ordem das funções não é importante ou seja, você não precisa declarar a função que você vai utilizar num bloco de texto antes de você utilizar, por exemplo:

fn main() {
	outra_funcao(); 
}

fn outra_funcao() {
  println!("Outra função");
}

No código acima mesmo a main estando a cima da outra_funcao, esse código ainda funcionará pois o que realmente importa é que a função esteja no escopo.

Parâmetros

Funções podem receber parâmetros que mudam como a função se comporta, veja o exemplo abaixo:

fn main() {  
    let z = soma(1,2);  
    let y = soma(1,3);  
  
    println!("Z : {}\nY : {}", z, y);  
}  
  
fn soma(a:i64,b:i64) -> i64{  
    a + b;  
}
}

Dentro da função main() chamamos a função soma duas vezes, passando argumentos diferentes para os parâmetros da função o que irá retornar um valor diferente para cada chamada.

Você pode ver que depois de declararmos o nome e os parâmetros da função temos -> esse símbolo representa o tipo do retorno da função.

Já dentro da função temos somente a linha a + b, essa linha retorna o resultado da soma de a mais b, isso pois em Rust não precisamos escrever return a + b, ele já é implícito.
