Busses - São caminhos utilizados para a comunicação de varios dispositivos dentro de um servidor, por exemplo entre a CPU e a as MEMORIAS RAMs nos temos busses DDR4 que fazem a comunicação entre eles, temos também caso seja um servidor dual CPU um bus para manter a coerencia entre as duas CPUs e por ai vai.

Temos diversos tipos de busses:

  • Shared ou Point to Point, Shared são varios dispositivos utilizando o mesmo bus, e o point to point são um bus dedicado para cada dispositivo.
  • Serial ou Parallel, serial é um bus com somente uma conexão para o dispositivo e parallel são diversas conexões que fazem o bus.
