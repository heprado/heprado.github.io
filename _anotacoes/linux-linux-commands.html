Less - pega um output e cospe na tela em partes e guarda o output até você apertar Q.

More - Faz a mesma coisa que o Less só que não guarda as coisas, o output some depois do comando.

Unset “variavel” - Libera o espaço de memoria de uma variavel

Export $variavel - Aloca um espaço de memoria global

Setar uma variavel dentro de uma shell - nome_variavel=$(cat arquivo | grep “palavra”)

Su - Troca de usuario (switch user) com o parametro - o sistema assume qual o seu /home

Sudo - executa um comando com poderes administrativos( só vale pra quem tem esses poderes)

Sudo su - Qualquer usuario com poderes administrativos consegue se tornar o root com esse comando.

Getent - Podemos usar para ver os grupos do sistema e os usuarios, só precisamos passar o parametro groups ou passwd.

Gpasswd -a “usuario” “grupo - Adicionar um usuario a um grupo, por exemplo o grupo de sudo.

loadkeys br-anbt2 - configura o usuario atual para utilizar o layout do teclado ABNT2.

mount “/dev/sdx” “/mnt/minha_particao” - Monta a partição dentro do segundo caminho.
