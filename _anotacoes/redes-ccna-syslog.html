Protocolo usado para enviar mensagens de LOG para um servidor, esse servidor também roda syslog.

Syslog usa UDP porta 514.

Syslog envia logs para um servidor centralizado, onde mais tarde uma pessoa pode ir lá verificar esses logs, isso é util.

As mensagens que aparecem de uma porta subindo, uma porta sendo colocada como administrative down, são mensagens syslog.

Formato da mensagem:

1- Timestamp
2- Lugar onde aconteceu o evento
3- Codigo do Log
4- Resumo do Log
5- Texto explicando de fato oque aconteceu.

Para configurarmos um switch/router para enviar logs para um servidor Syslog:

Logging host “ip”

Também podemos guardar as mensagens na memoria RAM (não recomendado):

Router(config)#Logging buffered
