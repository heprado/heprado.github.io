UCS Central é um gerenciador de UCS DOMAINS, um dominio é definido pelo UCS Manager, cada dominio só tem um UCS Manager que aguenta até 160 Servidores.

Para sincronizar o UCS Central com o UCS Manager os dois tem que ter exatamente a mesma configuração de horas.

Para um UCS Manager ser controlado pelo UCS Central, temos que marcar global na hora de registrar.

Se deixarmos Local, o UCS Central só vai ter informações sobre o dominio não vai conseguir configurar ele.
