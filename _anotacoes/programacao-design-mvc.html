O modelo mais famoso de arquiteura é o MVC, ele define 3 componentes:

  • View ( Front End)
  • Model (Dados)
  • Controller (Back End)

A view é responsavel por mostrar as informações para o usuário na tela através de um web browser ou um aplicativo de celular.

O model é responsavel por mandar as informações que vão ser renderizadas na View, ele conversa diretamente com a View e com a Controller.

A controller é responsavel pelos inputs do usuario, caso ele mude algo na View a Controller pega esses dados, encapsula de maneira que a Model consiga entender, e a Model manda os dados para a View renderizar.
