Protocolo utilizado para definirmos dinamicamente o estado de um porta pensando no protocolo 802.1Q, esse protocolo é bem útil pois caso um PC se conecte a uma porta de um switch, não precisamos configurar essa porta para switchport mode access manualmente, podemos só deixar como está que ele vai tomar conta do resto.

Para configurarmos dinamicamente qual será o protocolo usado no trunk (ISL ou 802.1Q) pode usar o comando:

Switchport trunk encapsulation negotiate

O DTP já vem ativo em todas as portas nos switches atuais e para configurarmos uma interface para o DTP caso não esteja é só utilizar o comando:

Switchport mode dynamic “desirable/auto”

  • Desirable - Sempre vai tentar fechar um trunk com o outro lado.
  • Auto - Aguarda receber alguma comunicação de um link trunk ou desirable, caso receba muda seu modo operacional para trunk.

Por padrão todas as portas de um switch vem como switchport mode dynamic auto, com isso o switch não vai tentar fechar um trunk em uma interface ligada a um PC, mas caso ele se conecte a um switch com uma porta configurada como trunk ou desirable, ele faz o trunk.

Por boas praticas a cisco diz para desabilitarmos o DTP nas interfaces e configurarmos na mão, principalmente para links trunk, para fazer isso:

Switchport nonegotiate
