Por padrão no K8s um Pod nunca pode ser recriado igualzinho a anteriormente, então como fazemos para uma aplicação ter somente um IP e DNS ?

Fazemos isso utilizando Services, eles recebem todo o tráfego e enviam para os Pods que fazem parte desse Service, ele também faz o update de roteamento para que todos os nós saibam onde um Pod está.

Quando definimos um serviço, definimos uma label que todos os pods que fazem parte do serviço precisam ter:

No caso acima o Service tem um selector chamado MyApp, todos os pods que forem participar desse serviço precisam ter a label MyApp para fazerem parte desse serviço.

Todos os nodes que tiverem um pod rodando a label MyApp vão expor o Service na porta 80 do IP do Node, para acessarmos
