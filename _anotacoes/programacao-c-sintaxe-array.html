Arrays são ajuntamentos de dados com tamanho definido que possuem o mesmo tipo, ou seja, só podemos colocar strings OU números OU booleanos e desses valores só podemos adicionar até o tamanho definido.

Exemplo 1 - Strings

Por exemplo eu tenho diversos nomes e quero guardar dentro de uma variável só e acessar elas pelo index, para fazer isso é só escrever o seguinte:

String[] nomes = new string[3] {"Felipe","Eduardo","Henrique"}; //Criando array e adicionando valores
const henrique = nomes[2] // Acessando o index 2 e pegando "Henrique"

O código acima pode ser interpretado da seguinte maneira, vamos criar um array de strings dentro desse array vamos alocar espaço para 3 strings e adicionar Felipe, Eduardo e Henrique dentro dele, após isso vamos criar uma constante chamada henrique com o valor dentro do index 2 do array.

Exemplo 2 - Números

Se quisermos criar um array de números inteiros com no máximo 3 números podemos fazer o seguinte:

int[] numbers = new int[3] // Criando array

numbers[0] = 1; //Adicionando valor
numbers[1] = 2; //Adicionando valor
numbers[2] = 3; //Adicionando valor

Int[] numbers cria um array chamado numbers, utilizamos o new int[3] porque precisamos alocar memoria para o array, abaixo disso ele está adicionando valores dentro desse array.
