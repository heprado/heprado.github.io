Resumo

- Trabalha no servidor.
- Interage com o banco de dados
- Valida regras de negocio.

Essa função é utilizada para processamento de dados basicamente, requisições chegam ao backend e toma a decisão de como essa requisição deve ser atendida, além de validar se estão alinhadas com as regras de negócios.

Essas requisições podem ser interagir com um banco de dados, uma execução de um script, ou ser redirecionado para outro serviço, etc…

Quem executa a função de Backend interage bastante com o Front-end para garantir que o servidor está pronto para receber as requisições do front-end.
