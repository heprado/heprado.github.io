No AppDynamics as metricas que são coletas todas passam por uma health rule, essa health rule calcula para ver se as metricas estão como o esperado ou não, caso não um evento é criado dentro da dashboard do AppDynamics.

Esses eventos que são criados podem triggar uma ação do AppDynamics, basicamente uma forma de automação em resolução de problemas. Para triggar essa ação precisamos criar uma policy que vai monitorar os eventos.


- Mandar uma notificação pra um email
- Começar uma diagnostic sessions para pegar full graph snapshots das transactions.
- Pegar um dump da thread que ta rodando a classe do programa que deu pau.
- Rodar um script .sh que está dentro dos nodes, o agente vai lá e starta eles, bem legal…
- Fazer uma requisição HTTP para alguma API externa, quem faz a requisição é a controladora.
- Usar auto-scaling de algumas nuvens publicas.
- Ou ações customizadas
