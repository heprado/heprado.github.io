O correto é nunca utilizarmos a branch master/main para desenvolvimento, nela só deve estar código que funciona em produção.

O melhor jeito é criar uma branch copia da master/main, caso queiramos arrumar um bug ou adicionar uma nova funcionalidade na aplicação, quando terminamos o codigo podemos fazer git merge com a master.

Comandos

  • git branch

Se usarmos somente como git branch ele mostra quais branches existem, se colocarmos git branch NOVA_BRANCH ele cria.

ESSA BRANCH É SÓ NO REPOSITORIO LOCAL.

  • git checkout

Esse comando troca de branch no repositorio local, assim quando fizermos um commit ele será guardado nessa branch.

git checkout NOVA_BRANCH

Git checkout -b NOVA_BRANCH , CRIA E MUDA SUA BRANCH ATUAL PARA A CRIADA.
