Em ansible temos um arquivo que chama ansible.cfg, esse arquivo possui diversas configurações do ansible em si, exemplos:

Eu posso ir até o arquivo ansible.cfg e escrever:

[defaults]
host_key_checking = False

Agora toda vez que eu rodar o ansible ele não vai parar naquele prompt para aceitarmos a fingerprint do certificado SSL tentamos fazer ssh pela primeira vez num servidor.

Também é no ansible.cfg que referenciamos qual vai ser o arquivo de inventário que o ansible vai usar.

O arquivo de configurações pode ficar em vários lugares do servidor que você irá utilizar para rodar o playbook, mas possuem uma prioridade para qual o ansible vai escolher como o principal:

Ordem de Prioridade:
  1. Variável de ambiente ANSIBLE_CONFIG , podemos utiliza-la para especificar o diretório dentro do servidor do arquivo de configuração.
  2. ansible.cfg no diretório que estivermos executando o ansible
  3. ~/.ansible.cfg, se o arquivo estiver como oculto e no diretorio home do seu usuario.
  4. /etc/ansible/ansible.cfg, esse arquivo só é criado automaticamente caso você use um package manager(yum,apt,snap,dnf) para instalar o
