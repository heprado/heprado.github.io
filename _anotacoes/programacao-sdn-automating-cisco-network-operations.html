Day 1 - Fazer a configuração desse equipamentos após ele ser colocado dentro da rede.

Day 3 - Fazer ajustes nas configurações, upgrade de versão de software etc.

Tipos de SDN

1 - Nesse primeiro caso de SDN os equipamentos só apresentam uma API geralmente utilizando protocolos como NETCONF e RESTCONF, assim aplicações conseguem gerenciar o equipamentos, em Data Center um exemplo seria o DNCM configurando um NX-OS através das NX API.

2a - Pure SDN, aqui temos uma controladora que tirou TODO o control plane do hardware, ele foi todo para o software, então decisões de roteamento e encaminhamento são todas tomadas dentro da controladora e passada para o Data Plane do equipamento atráves de APIs, utilizando protocolos como OpenFlow e NETCONF.

2b Hybrid SDN, essa arquitetura é utilizada pelo ACI, nesse caso ainda temos uma parte do Control Plane dentro do Switch/Router, para ele conseguir tomar suas próprias decisões de roteamento, acredito que isso para ele conseguir fazer switching cut-through pois perguntar tudo para a controladora poderia trazer latência numa rede de Data Center.

3b Overlays Network, nesse caso criamos redes virtuais por cima da rede existente, assim conseguimos fazer a automação por esse rede Overlay, geralmente o protocolo utilizado é VXLAN para fazer o overlay, com um protocolo de roteamento underlay como MP-BGP ou ISIS.
