EUM(End User Monitoring) é uma funcionalidade do AppD que monitora por onde um usuário passou na sua aplicação, fim a fim.

Com isso conseguimos tirar informações valiosas para o business, por exemplo uma aplicação de vendas, conseguimos ver em qual parte da aplicação o usuário pode ter desistido de uma compra.

Existem 4 modelos de EUM:

  • Browser Real User Monitoring, quando um usuario acessar sua aplicação um script javascript será injetado dentro do browser, esse é o agente do Browser Real User Monitoring, esse script envia informações de como o usuario se comporta na sua aplicação.

  • Mobile Real User Monitoring, um agente é instalado dentro do seu aplicativo de celular, esse agente coleta as informações de usuario e envia para a controladora, suporta react/xamarin/cordova ou iOS nativo.

  • IoT Monitoring, nesse modelo a aplicação que está rodando no dispositivo IoT precisa ser instrumentada para mandar metricas para o EUM Server ou para a Rest API do AppD de IoT, use cases maneiros são por exemplo pontos de venda com problemas.

  • Browser Synthetic Monitoring, são browser sinteticos hospedados na nuvem, eles ficam a todo momento acessando a sua aplicação como se fossem usuarios, assim podendo testar a perfomance dela.
