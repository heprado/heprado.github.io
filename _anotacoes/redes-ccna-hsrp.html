Protocolo FHRP(First Hop Redundancy Protocol)

Protocolo utilizado para criarmos gateways redundantes, os roteadores irão usar um IP virtual que será o gateway das maquinas, e um mac virtual.

O MAC Virtual é necessario pois os computadores vão manter o MAC do Roteador salvo por até 5 minutos, ele não vai mandar uma ARP request imediatamente, assim perdendo a comunicação. Com o MAC Virtual os dois roteadores compartilham do mesmo MAC Address.

GARP - Quando um roteador falha no HSRP, o roteador que assumir o controle vai enviar um GARP(Gratuitous ARP),
com origem sendo o mac virtual e destino FF:FF:FF:FF:FF:FF, atualizando a tabela MAC de todos os switches, para saberem qual porta ele está conectado.

HSRP V1 -

  • Hello Timer de no minimo 1 segundo.

  • 256 grupos standby

  • MAC VIRTUAL PADRÃO 0000.00c7.ac01(os ultimos dois digitos significam o numero do grupo)

HSRP V2 -

  • Hello timer podem ser configurados para milisegundos.

  • 4096 grupos standby(um pra cada VLAN)

  • MAC VIRTUAL PADRÃO 0000.0c9f.f213( os ultimos tres digitos significam o numero do grupo)

A versão de HSRP TEM QUE BATER NOS DOIS ROTEADORES, UM ROTEADOR VERSÃO 1 NÃO FECHA GRUPO COM UM VERSÃO 2
