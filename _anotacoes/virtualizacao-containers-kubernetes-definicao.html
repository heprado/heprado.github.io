A principal diferença entre um container e uma VM é que cada VM tem um OS, o Container usa o Kernel do OS que está instalado no servidor.

Um container por conta do seu tamanho, pode ser estabelecido em segundos, já uma VM as vezes precisa de minutos para subir, por conta do sistema operacional pesado que está junto com ela.

Kubernetes

Nodes

  • são maquinas onde seus containers estão rodando.
  • Tem kubelet rodando neles, kubelet serve para verificar se todos os containers estão rodando como esperado no node.

Clusters
- É um conjunto de nodes juntos.
- Divide o load entre os nodes.

Master
- É um outro node que tem o K8s instalado, ele controla os outros nodes do cluster.
- Ele que gerencia o load-balance dos nodes.
- Caso um Node falhe ele passa para outro node, ou cria outro node e passa para ele os workloads.
- Interagimos com ele via API,exemplo CLI.
- Scheduler executa as tarefas programas, um exemplo seria criar um container no node, caso o workload esteja muito alto.
- Etcd armazena as informações sobre como os clusters estão organizados e logs.
- Controller, responsavel por analisar o ambiente, ele repara se algum node caiu e manda o scheduler subir outro.

Kubectl
- Usamos para controlar o nodes.
- Kubectl run,executa uma aplicação
- Kubectl cluster-info,mostra as informações do cluster
- Kubectl get nodes,mostra as informações dos nodes.

Minikube
- Ferramenta usada para cria um master e um node só.
- Usada para rodar kubernetes no seu notebook,etc (testes)
