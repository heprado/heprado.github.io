IOS Boot Process

Processo de boot de router/switch
****
1. Faz um POST para verificar o que está conectado nele, e se está tudo ok com o hardware.
2. Se estivar tudo ok , ele copia o programa de bootstrap para a RAM e executa ele.
3. Se algo tiver dado errado o bootstrap copia a ROMMON na RAM e executa ela.
4. O Bootstrap escolhe a IOS que esta na flash executa e coloca na RAM.
5. Após isso o bootstrap passa o controle para a IOS.
6. O IOS pega a Startup-config da NVRAM e copia para a RAM como Running-config

Configurando Registros

Registros são configurações que o router checa na hora de bootar a IOS, eles são representados em numeros hexadecimais(0x2100),
Podemos usar essa configuração para por exemplo, bootar a ROMMON ao em vez da IOS, mesmo estando tudo ok com o router/switch.

O ultimo numero hexadecimal define o que vai acontecer no boot:

Se for 0 vai bootar na ROMMON

Se for 1 vai bootar a primeiro imagem na flash

Se for 2 vai bootar alguma imagem na flash definida pelo comando boot system, se não tiver nenhum boot system boota a primeira imagem na flash.
