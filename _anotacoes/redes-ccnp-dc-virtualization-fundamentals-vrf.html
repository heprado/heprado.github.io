Uma VRF é como se fosse outra instancia de roteamento dentro de um roteador, eu gosto de me referir a VRFs como VLANs de IP, uma VRF não conversa com a outra por padrão e cada uma possui sua propria RIB e FIB, podemos configurar uma VRF Leaking para passarmos rotas de uma VRF para outro VRF, mas isso não é tão comum.

Diferente de uma VLAN que divide somente o control plane dos switches, as VRFs dividem o control plane e o data plane, cada VRF tem sua propria FIB no Data Plane.
