Protocolo Advanced Distance Vector, utiliza hello packets igual ao OSPF para manter vizinhança.

Ele cria uma rota principal para cada destino e uma rota chamada Feasible Successor que é a rota de Backup.

Terminologia:

Feasible Distance: Distancia de um roteador para um destino(ROTA)

Advertised Distance:

Distacia do proximo salto para esse destino(ROTA)

Successor: Rota principal na Topology Table

Feasible Successor: Rota de Backup na Topology Table

Active Route: é uma rota tentando achar uma rota de backup na Topology Table

Passive Route: Uma rota que está funcionando na Topology Table.

Tabelas EIGRP

Ele mantém 3 tabelas:

Neighbor Table:
Tabela de roteadores vizinhos

Topology Table:
Nessa tabela temos as informações de todas as Successor Routes(ROTAS PRINCIPAIS) e Feasible Sucessor(ROTAS SECUNDARIAS)

Routing Table:
Tabela de roteamento, onde vão estar todas as rotas que o EIGRP vai estar usando.

Mensagens do EIGRP

K VALUES

O EIGRP por padrão utiliza somente o Bandwidth e o Delay para calcular sua metrica, mas ele pode utilizar todas as outras.

OS K VALUES DEVEM SER IGUAIS EM AMBOS OS ROTEADORES PARA QUE A VIZINHANÇA SEJÁ FORMADA.

https://www.practicalnetworking.net/stand-alone/eigrp-feasibility-condition/

DUAL

É o processo de perguntar uma rota para um neighbor caso a Successor Route e a Feasible Route tiverem caido.

Ele faz isso mandando um query para o neighbor, que responde com o reply dizendo se tem uma rota ou não para a rede.

Hello Timers e Hold Timers

Hello Timer: Tempo em que o roteador vai enviar um Hello Packet.

Hold timer: Caso um roteador não receba um hello nesse tempo, considerar ele morto.

O Hold Timer sempre é 3 vezes o tempo do Hello Timer, por padrão o EIGRP coloca 5 segundos para links considerados rapidos e 60 segundos para links considerados lentos.

Então em um link FastEthernet o Hello Timer seria 5 segundos e o Hold Timer seria 15 segundos.
