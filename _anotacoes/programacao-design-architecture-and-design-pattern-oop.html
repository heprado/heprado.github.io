Programação Orientada a Objetos

Programação orientada a objetos é composta por 4 principios:

  • Abstraction
  • Encapsulation
  • Polymorphism
  • Inheritence

Abstraction

Um metodo abstrato dentro de uma classe significa que as classes filhas não vão conseguir utilizar esse metodo, ele só vai ser UTIL DENTRO DA CLASSE PAI. Cada classe filha vai ter que criar sua propria implementação desse metodo como por exemplo no caso abaixo:

A classe payment(PAI) possui dois metodos, a print_slip um metodo normal que vai ser herdado pelas classes filhas e um metodo payment que possui um @abstractmethod antes dizendo que é um metodo abstrato, quando instaciarmos um objeto de uma das classes filhas como a CreditCardPayment, não conseguimos utilizar o metodo payment da classe pai que é Payment pois é um metodo abstrato, mas conseguimos utilizar o metodo print_slip no objeto, referenciando ao metodo da classe pai que não é abstrato.

Encapsulation

É uma forma de fazer dados não poderem ser alterados ou referenciados em outras classes filhas ou instancias delas.
Em python não tem metodos e nem parametros privados de uma função, só conseguimos por um double underscore antes deles para dizer que pertencem a essa classe e não podem ser modificados por subclasses.

Polymorphism

Em python é uma função que consegue ser usada para diferentes tipos, temos também o method overriding que é quando temos uma classe filha tendo um metodo com o mesmo nome da classe pai, só que ela faz coisas diferentes.
