VLANs Pools

É o equivalente ao comando switchport trunk allowed vlan “VLANS”, nessa policy especificamos quais VLANs vão poder passar pelo trunk das interfaces que colocarmos essa policy.

Temos dois tipos de VLANs Pools Policies

Static - Todas as VLANs que adicionarmos nas pools vão ser permitidas, independente delas estiverem sendo usadas ou não.
Dynamic - Se o ACI tiver integrado com o vSwitch da vmware, não faz diferença qual VLAN está sendo usada, pois o ACI consegue passar o tráfego layer 2 pelo layer 3, então o ACI falaria para o vSwitch escolher uma VLAN aleatoria para o port-group da maquina virtual. Por fim o ACI faz a conectividade via EPGs, então contanto que as maquinas virtuais estejam no mesmo EPG, elas vão conseguir se comunicar.

SE FOR UTILIZAR A INTEGRAÇÃO DO ACI COM O vDS DA VMWARE É OBRIGATORIO USAR DYNAMIC.

SE ESTIVER USANDO UMA REDE LEGADO, USAR STATIC, POIS O ACI NÃO CONTROLA OS SWITCHES DA REDE LEGADO, E TERIAMOS PROBLEMAS DE VLANS CONFIGURADAS ERRADO.

Domains Policies

As domains policies definem como um endpoint se conecta ao ACI, assim quando mapearmos o domain com um EPG, ele vai saber quando um Endpoint novo aparecer.

O Fisico existe para quando um host bare-metal se conectar a uma interface do leaf, o ACI saber a qual EPG ele pertence.

O Virtual existe para quando uma maquina virtual aparecer em um certo port-group que está mapeado para esse EPG, ele apareça no ACI como sendo desse EPG.

Physical Domain Policy - Nessa policy especificamos que o endpoint se conecta fisicamente com o leaf, as vezes ele pode ser conecta através de outro switch.

Virtual Domain Policy - Nessa policy especificamos que o endpoint se conecta virtual com o leaf, através de um vSwitch ou algum switch virtual que tenha integração com o ACI, vale apontar que caso o ACI não tenha integração com o switch virtual que vc estiver usando, ele vai tratar essa policy como uma Physical, porque ele não consegue diferenciar um host bare-metal de um host virtual sem integração.

External Bridged Domain - É usado quando precisamos estender o Layer 2 por um switch não ACI, para um endpoint conseguir se conectar.

External Routed Domain - É usado quando precisamos estender o Layer 3 por algum outro equipamento Layer 3, para um endpoint conseguir se conectar.

Attachable Access Entity Profile(AAEP)

É uma Policy usada para juntar os dominios com um Interface Policy Group, podemos ter diversos dominios em um AAEP.

Interface Policies

São profiles utilizados para definir como a interface vai se comportar, se o CDP vai estar enable, se o LLDP vai estar disabled, qual a velocidade e etc, no final linkamos essas Interface Policies na Interface Profile.

Interface Policy Groups -

São uma junção de todas as Interface Policies que vc configurou em um único grupo, no IPG escolhemos também a qual AAEP esse interface policy group pertence, assim atrelando as Interfaces com o Dominio escolhido.

Existem três tipos de IPG:

Access : Quando formos conectar um servidor com só uma interface escolhemos essa opção.
Port Channel : Quando formos conectar um servidor em duas interfaces escolhemos essa opção.
vPC: Quando formos conectar um servidor em 2 interfaces de switches diferentes escolhemos essa opção.

Interface Profile

O interface profile junta os IPGs com os Interface Selector, o Interface Selector seleciona quais portas vamos usar, após isso nos ligamos o Interface Profile com o Switch que queremos configurar.

Interface Profile Override, é quando precisamos fazer uma configuração por cima de um Interface Selector, digamos que vc fez um selector 1/2-1/5, mas precisamos uma configuração especifica para a 1/3, com isso podemos fazer uma Interface Profile Override.

Switch Policies

Os switches Policies, servem para configurarmos o Switch, protocolos como STP,vPC e BFD são configurados nessas policies, por fim juntamos essas Switches Policies com um Switch Profile, igual as interfaces.

Switch Profile

No Switch Profile, juntamos tudo, as Switch Policies para configurarmos os Switches, e a Interface Profile para configurarmos as portas dos Leafs.
