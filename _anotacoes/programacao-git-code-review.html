Code Review é onde o pessoal revisa o código para achar bugs, fazer melhorias como deixar ele mais performático ou deixar mais human readable.

Quem faz o code review é quem não escreveu esse codigo, isso para não influenciar a review do código, assim a pessoa que faz o review consegue identificar bugs mais facilmente, aprender coisas novas e conhecer mais sobre o projeto, isso tudo previne do software quebrar em produção e dar prejuízos enormes para as empresas.

No github code review funciona da seguinte forma:

  • Crie uma branch para a nova funcionalidade.
  • Faça um commit do novo codigo para o repositorio remoto.
  • Crie um Pull Request
  • Rode os testes em cima do codigo
  • Code Review!
  • Merge da branch na master :)
