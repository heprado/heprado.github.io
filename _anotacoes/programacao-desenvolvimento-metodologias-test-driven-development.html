Em Agile como os codigos são entregues em pequenos updates diferente do que em Waterfall que são entregues em grandes updates, podemos fazer mais testes, isso ajuda bastante na hora de resolver bugs.

TDD(Test-Drive Development) diz para escrevermos primeiro o teste e depois o source code, isso é interessante pois os nossos testes não vão ser influenciados pelo que escrevemos no test code.

Funciona da seguinte maneira:

  • Escrevemos os testes
  • Testamos o Test, todos devem dar erro.
  • Escrevemos o Source Code.
  • Testamos o Source code com o test.
  • Arrumar as partes do codigo que não passaram no test.
  • Revisar o código, e fazer melhorias para otimizar o máximo possível.
