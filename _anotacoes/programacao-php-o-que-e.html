PHP é uma linguagem feita para renderizar HTML basicamente, tu consegue passar valores pro HTML gerando paginas dinâmicas, isso abrindo diversas possibilidades.

Todo arquivo .php aceita HTML, para escrever PHP você PRECISA escrever a tag .

<?php
	$meu_nome = "Henrique";
?>

<html>
	<h1> Oi Mundo eu sou <?php echo $meu_nome;?>	
</html>

No caso sempre que a pagina for acessada ela vai ser renderizada com o valor da variável $meu_nome.
