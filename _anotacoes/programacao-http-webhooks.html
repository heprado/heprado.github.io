Hoje em dia os sistemas estão muito integrados então temos um problema, caso um sistema depende de informações de outro quando algo mudar, ele ia precisar ficar perguntando como na imagem abaixo:

Isso é ruim pra caramba, varias requisições sendo feitas só pra ver se tem algo novo, para isso existem os WEBHOOKS, que faz com que a API mande uma request falando que algo novo aconteceu:

Funciona da forma inversa, o cliente faz um POST para se subscrever nesse webhook passando informações sobre que porta ele vai ficar ouvindo essas notificações e quais ele quer ouvir, também autenticação, ai toda vez que um evento ocorrer a API vai avisar o cliente fazendo um POST Request pro cliente.
