É um modulo do java que podemos utilizar para tratar requisições HTTP, ele não necessariamente é um servidor WEB como no python, ele recebe alguma informação via HTTP e executa uma função mas não serve a pagina estatica necessariamente, para isso utilizamos o Tomcat, que recebe as requisições nas URLs e envia para os servlets que estão mapeados por ele, não necessariamente esse servlet vai estar rodando na mesma maquina que o tomcat
