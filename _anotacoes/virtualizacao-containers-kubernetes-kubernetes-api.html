A API do Kubernetes é uma API Restful baseada em HTTP usando JSON, então podemos fazer qualquer metodo de requisição HTTP como GET/POST/PUT/PATCH/DELETE etc.

Ela é a única forma de interagir com o cluster de K8s e dentro delas temos os API Objects, que são objetos que a API cria dentro do etcd com toda a configuração do cluster, é nela também que definimos o estado da aplicação e do cluster em si.

Temos duas formas de interagir com a API:

  • Declaratively : Escrevemos um yaml file com as configurações que desejamos aplicar no cluster e enviamos para a API, ela interpreta serializa os dados aplica as configurações e salva tudo dentro do ETCD.
  • Imperatively : Nesse modo interagimos com o K8s atráves de uma CLI como a kubectl ou kubeadm, e escrevemos comandos que mandam o cluster K8s agir de certa forma.
