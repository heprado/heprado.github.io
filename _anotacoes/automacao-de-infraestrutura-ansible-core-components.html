Executável

Ansible é utilizado através de um executável que podemos baixar no site da RedHat, esse executável consegue interpretar os módulos criados pela comunidade e é a nossa ferramenta principal para utilizarmos o ansible.

Módulos

Módulos possuem funcionalidades para automatizar diversas tarefas relacionadas ao software/hardware que você quer configurar, se você possui familiaridade com Terraform eles são semelhantes aos provedores(Providers), eles são escritos pela comunidade ou por empresas e você pode utilizar um ou uma combinação de diversos deles para executar todas as configurações necessárias para sua infraestrutura.

Playbook

Cada ação executada pelo ansible é chamada de play, essas plays podem ser agrupadas em ansible playbooks, , quando chamamos o ansible-playbook ele lê os comandos e executa eles.

Inventários

O ansible aplica as configurações nos equipamentos que definirmos no arquivo de inventario, esse arquivo pode conter por exemplo IPs ou Hostnames de :

  • Servidores Linux/Windows .
  • Gerencia de equipamentos de rede.
  • Container .
  • Servidor com docker rodando dentro.
  • Gerencia de um storage array.

Existem também os inventários dinâmicos (dynamic inventories) pois as vezes precisamos configurar uma infraestrutura que não sabemos ainda qual vão ser os endereços para nos conectarmos para executar as plays, com os inventários dinâmicos conseguimos puxar as informações de outra origem, um exemplo seria consultarmos via API o IP público de uma máquina virtual que a AWS está hospedando para nós.
