Constantes em Rust diferentes de variáveis são imutáveis, após a inicialização da constante, o valor dela não poderá ser mudado nunca.

Por exemplo:

fn main () {
  //Criando a variavel VERMELHO com a Sequencia de escape ANSI 
  //para vermelho
  const VERMELHO = "\x1b[31m";
  
  const VERMELHO = "\1b[35m";
}

O código a cima não irá compilar pois estamos redeclarando uma constante com o mesmo nome no MESMO ESCOPO.

Constantes são úteis para valores que não mudam, como códigos ANSII de sequencias de escape, podemos definir a constante no escopo global do nosso programa colocando a constante fora da main(), assim ela nunca será mudada e poderá ser acessada por todos.

const VERMELHO = "\x1b[31m";
const RESETAR_COR = "\x1b[0m"

fn main() {
  println!("{} Oieeee {}",VERMELHO,RESETAR_COR)
}
