Pontos chave

  • São imutáveis por padrão, isso significa, após serem inicializadas o valor dela não pode ser alterado de forma alguma.
  • Para tornarmos uma variável mutável devemos utilizar a palavra-chave mut
  • Quando tentarmos compilar um código rust com uma variável imutável sendo atribuída valores múltiplas vezes, o compilador avisa.
  • Se precisarmos mudar o valor de uma variável imutável devemos criar um novo escopo.

Mutabilidade / Imutabilidade

Em Rust precisamos especificar se uma variável após sua criação pode ter seu valor alterado, pois por padrão todas as variáveis são imutáveis ou seja não podem ter seu valor alterado após a inicialização.

Declarando uma variável imutável :

let variavel:&str = "Valor"

Declarando uma variável mutável:

//Note a palavra chave mut.
let mut variavel:&str = "Valor"

Imutabilidade

De uma olhada:

fn main() {

  //Variável imutável
  //O tipo é um ponteiro para uma string.
  let nome: &str = "Henrique";
  
  println!("Oi meu nome é {}",nome);
  
  //Tentando alterar o valor da variável.
  //Não ira funcionar.
  nome = "Outro nome";
  
  println!("Oi meu nome é {}",nome);
  
}

O código acima não compilaria por conta de termos uma variável imutável e estarmos adicionando outro valor, em nome = "Outro Nome".

Mutabilidade

Para podermos modificar o valor de uma variável precisamos utilizar a palavra-chave mut :

fn main() {

  //Variável mutável
  //Tipo é um ponteiro para uma string.
  let mut nome: &str = "Henrique";
  

  println!("Oi meu nome é {}",nome);
  
  //Atualizando a variável nome.
  //Isso funciona por conta da variável ser let mut
  nome = "Outro nome";
  
  println!("Oi meu novo nome é {}",nome);
}

O código acima compilaria e teria a saída dessa forma:

Oi meu nome é Henrique
Oi meu novo nome é Outro nome

Variáveis mutáveis são uteis para quando precisamos alterar o valor da variável múltiplas vezes.

Sombreamento

Escopos

Mesmo uma variável sendo imutável nada te impede de criar uma nova variável com o mesmo nome que a anterior só que em um novo escopo, veja o exemplo abaixo:


//Ponteiro imutável()  
//para uma string.  
let nome:& str = "Henrique";  
  
//Imprimindo no STDIN o nome dentro da variável nome  
println!("Nome no escopo 0 {}", nome);  
  
//Criando um novo escopo  
{  
    //Criando outro ponteiro imutável para uma string, 
    //utilizando o   mesmo nome de variável.  
    //Isso só é possivel pois estamos em outro escopo.    
    let nome:& str = "Sombra Henrique";  
  
    //Imprimindo no STDIN o novo nome dentro da variavel nome  
    println!("Nome no escopo 1 {}", nome);  
}

O código acima só compila pois criamos um novo escopo e definimos uma nova variável com o mesmo nome, isso faz com que o compilador entenda que até o fim da execução daquele escopo o valor da variável será o novo.

Escopos com condições

Escopos podem estar em qualquer lugar do seu código, veja por exemplo a criação de um escopo baseado em uma condição:

//Ponteiro imutável(Não pode ser outra string em tempo de execução)  
//para uma string.  
let nome:&str = "Henrique";  
  
//Imprimindo no STDIN o nome dentro da variável nome  
println!("Nome no escopo {}", nome);  
  
//Criando um novo escopo caso o nome seja Henrique.  
if nome == "Henrique" {  
  
    //Criando outro ponteiro imutável para uma string,
    //utilizando o mesmo nome de variável.  
    //Isso só é possivel pois estamos em outro escopo.    
    //O interessante aqui é que estamos dentro de um escopo contextual, 
    //podemos criar um escopo diferente para cada valor atribuido a  
    //variavel quando ela for inicializada.    
    let nome:&str = "Sombra Henrique";  
    println!("Nome dentro do escopo do if {}", nome);  
}

No caso acima o escopo só será criado caso o valor dentro da variável for a string “Henrique”.
