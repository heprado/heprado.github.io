Geneve é um protocolo de underlay utilizado pela Vmware para fechar tuneis de data plane entre os hosts ESXi, é praticamente igual ao VXLAN, a principal diferença é que o GENEVE foi criado pensando em não só transportar o VNI da rede overlay, mas também possibilitar outras implementações em cima do protocolo.

Principais partes do header :

  • Protocol Type, fala qual protocolo está encapsulado dentro do tunel geralmente é Ethernet.
  • VNI, o ID do tunel
  • Variable Lenght Options, espaço onde podemos inserir novas funcionalidades ao GENEVE, sem o IETF lançar uma revisão nova do protocolo.
