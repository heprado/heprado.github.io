Role Based Access Control

Configurando os perfis do operador em ADMIN>AAA>Security>Roles :

Para a Role escolhemos os privilégios, todos eles são definidos por padrão e podemos encontrar quais permissões eles dão no site : https://www.cisco.com/c/en/us/td/docs/switches/datacenter/aci/apic/sw/2-x/Security_config/b_Cisco_APIC_Security_Configuration_Guide/b_Cisco_APIC_Security_Guide_chapter_01000.html#concept_A5EAE4EC5E164965B42AD0364B55E9CB

No meu caso vou usar o privilegio tenant-security, que da acesso somente aos contratos de um tenant.

Após isso precisamos criar um Security Domain, esse dominio define qual tenants vamos poder acessar.

Agora vamos configurar um novo usuário sobre a aba ADMIN>AAA>Users

A primeira aba da configuração é bem simples, somente preencher com usuário e senha e clicar em next.

Após isso escolhemos o Security Domain que criamos

Agora escolhemos a role que configuramos e o tipo do privilegio, se o operador só puder ver as configurações em READ, se ele puder modificar
escolher WRITE

Entre na aba Policy do seu Tenant e clique em Security Domains e escolha o Security Domain que vc criou para seu usuário.

Logue com seu novo usuário, agora as abas que o usuário não tem acesso estarão em cinza e somente o tenant que colocamos o Security Domain vai aparecer

Como o privilegio que escolhemos foi o tenant-security e colocamos como READ o usuário só poderá criar e ver contratos, no exemplo abaixo tentei criar um Bridge Domain
e não consegui pois meu usuário não tem esse privilegio, mas consigo criar contratos normalmente.
